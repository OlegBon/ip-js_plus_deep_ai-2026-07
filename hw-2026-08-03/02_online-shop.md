# 🛒 E-commerce Storefront & Admin Panel

Концепт кастомного інтернет-магазину (Boutique E-commerce) з кошиком, оформленням замовлень і повнофункціональною адміністративною панеллю керування товарами.

---

## 🛠 1. Технологічний стек

Для реалізації швидкої вітрини (з урахуванням SEO) і надійної обробки замовлень обрано такий стек:

- **Фреймворк:** Next.js (App Router). SSR для оптимізації карток товарів і швидкого завантаження.
- **Стилізація:** Tailwind CSS + Shadcn UI (для складних компонентів, як-от форми та виїзний кошик).
- **Керування станом:** Zustand або React Context + LocalStorage (для збереження стану кошика під час перезавантаження сторінки).
- **База даних:** PostgreSQL + Prisma ORM.
- **Медіасховище:** Cloudinary або AWS S3 (у базі зберігаються лише URL зображень).

---

## 📦 2. Тематика й каталог товарів

**Ніша:** бутик преміальних зоотоварів.
Базовий асортимент для тестування кошика та підрахунку підсумкових сум:

1.  Ортопедична лежанка «Хмаринка» — 1 200 грн. (Категорія: сон)
2.  Інтерактивна мишка на радіокеруванні — 650 грн. (Категорія: іграшки)
3.  Керамічний фонтанчик-поїлка (2 л) — 1 500 грн. (Категорія: посуд)
4.  Автоматична годівниця з таймером — 2 300 грн. (Категорія: гаджети)
5.  Набір органічних ласощів (лосось) — 250 грн. (Категорія: їжа)

## 🖥 3. Структура сторінок і UX/UI

### Вітрина (Storefront)

- **Головна сторінка (`/`):**
  - _Hero-блок:_ великий банер із закликом до дії.
  - _Product Grid:_ сітка карток товарів (фото, назва, ціна, кнопка «Додати в кошик»).
- **Сторінка товару (`/product/[id]`):**
  - галерея зображень (основне фото + мініатюри);
  - інформаційний блок: докладний опис, статус наявності, акцентна кнопка покупки.
- **Віджет кошика (Cart Drawer):**
  - виїзна бічна панель (Slide-over) після кліку на іконку в хедері;
  - містить список доданих товарів (із можливістю змінити кількість і видалити), підсумкову суму;
  - перемикається на форму оформлення (ім'я, телефон, адреса/відділення) після кліку на «Оформити замовлення».

### Адмінпанель (Dashboard)

- **Зведення (`/admin`):** базова аналітика за період (кількість замовлень, виручка) — **⚠️ цей пункт необов'язковий)**.
  **За рекомендаціями безпеки такий очевидний шлях краще не робити :)**
  **Прихований ендпоїнт /admin/login.**
- **Товари (`/admin/products`):** керування каталогом.
- **Замовлення (`/admin/orders`):** обробка заявок, що надходять від клієнтів.

---

## 🔐 4. Авторизація та безпека (Admin Only)

У базовій версії особисті кабінети для покупців не передбачені, тому система авторизації захищає лише адміністративну частину.

- **Маршрут:** прихований ендпоїнт `/admin/login`.
- **Реалізація:** NextAuth.js (Auth.js) із провайдером `Credentials` (Email + пароль).
- **Відновлення доступу:** резервний вхід через Telegram-бота (генерація одноразового Magic Link за запитом адміністратора).

---

## ⚙️ 5. Керування товарами й замовленнями (CRUD)

### Логіка роботи з товарами

Реалізовано повний цикл керування в адмінпанелі:

- **Create & Update:** форми для додавання/редагування (назва, опис, ціна, завантаження фото).
- **Read:** табличне відображення з пагінацією.
- **Delete (Soft Delete):** щоб не зламати історію старих замовлень, товари не видаляються з БД фізично. Натомість змінюється прапорець `isActive: false`, що приховує товар із вітрини.

### Механізм сповіщення про замовлення

1.  Покупець надсилає форму з віджета кошика.
2.  Next.js API Route формує записи в таблицях `Order` і `OrderItem` (PostgreSQL).
3.  Сервер асинхронно надсилає HTTP-запит до Telegram Bot API.
4.  Адміністратор отримує push-сповіщення в Telegram із деталями замовлення (сума, контакти, склад замовлення) для оперативного зв'язку з клієнтом.

## 🚀 6. Додаткові опції (масштабування)

Архітектура проєкту дає змогу в майбутньому впровадити:

- **Особистий кабінет клієнта:** інтеграція OAuth (Google/Apple), збереження історії замовлень, прив'язка кошика до профілю (БД) замість LocalStorage.
- **Розширена навігація:** впровадження системи категорій, тегів і клієнтської фільтрації за ціною/характеристиками.
- **Онлайн-оплата:** інтеграція платіжних шлюзів (Stripe / LiqPay).

---

## 🎨 7. Візуальні референси

- **Вітрина:** мінімалізм у стилі D2C-брендів (багато білого простору, великі фото, залипаючий хедер).
- **Кошик:** класичний патерн Shopify (чистий Drawer, що затемнює основний вміст).
- **Адмінка:** строгий технічний дизайн у стилі Vercel Dashboard або Tailwind UI (щільна сітка даних, темний сайдбар навігації).

**⚠️ Тут ніби трохи бракує деталей реалізації (опису словами, не псевдокодом), але на цьому етапі не страшно.**
