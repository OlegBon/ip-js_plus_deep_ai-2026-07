# 🛒 E-commerce Storefront & Admin Panel

Концепт кастомного интернет-магазина (Boutique E-commerce) с корзиной, оформлением заказов и полнофункциональной административной панелью управления товарами.

---

## 🛠 1. Технологический стек

Для реализации быстрой витрины (с учетом SEO) и надежной обработки заказов выбран следующий стек:

- **Фреймворк:** Next.js (App Router). SSR для оптимизации карточек товаров и быстрой загрузки.
- **Стилизация:** Tailwind CSS + Shadcn UI (для сложных компонентов, вроде форм и выезжающей корзины).
- **Управление состоянием:** Zustand или React Context + LocalStorage (для сохранения состояния корзины при перезагрузке страницы).
- **База данных:** PostgreSQL + Prisma ORM.
- **Медиа-хранилище:** Cloudinary или AWS S3 (в базе хранятся только URL изображений).

## 🖥 3. Структура страниц и UX/UI

### Витрина (Storefront)

- **Главная страница (`/`):**
  - _Hero-блок:_ Крупный баннер с призывом к действию.
  - _Product Grid:_ Сетка карточек товаров (Фото, Название, Цена, кнопка "Добавить в корзину").
- **Страница товара (`/product/[id]`):**
  - Галерея изображений (основное фото + миниатюры).
  - Информационный блок: подробное описание, статус наличия, акцентная кнопка покупки.
- **Виджет корзины (Cart Drawer):**
  - Выезжающая боковая панель (Slide-over) при клике на иконку в хедере.
  - Содержит список добавленных товаров (с возможностью изменения количества и удаления), итоговую сумму.
  - Переключается на форму оформления (Имя, Телефон, Адрес/Отделение) по клику на "Оформить заказ".

### Админ-панель (Dashboard)

- **Сводка (`/admin`):** Базовая аналитика за период (количество заказов, выручка) - **⚠️ Этот пункт необязателен)**.
  **По рекомендация безопасности такой очевидный путь лучше не делать :)**
  **Скрытый эндпоинт /admin/login.**.
- **Товары (`/admin/products`):** Управление каталогом.
- **Заказы (`/admin/orders`):** Обработка поступающих заявок от клиентов.

---

## 🔐 4. Авторизация и безопасность (Admin Only)

В базовой версии личные кабинеты для покупателей не предусмотрены, поэтому система авторизации защищает только административную часть.

- **Маршрут:** Скрытый эндпоинт `/admin/login`.
- **Реализация:** NextAuth.js (Auth.js) с провайдером `Credentials` (Email + Пароль).
- **Восстановление доступа:** Резервный вход через Telegram-бота (генерация одноразовой Magic Link по запросу администратора).

---

## ⚙️ 5. Управление товарами и заказами (CRUD)

### Логика работы с товарами

Реализован полный цикл управления в админ-панели:

- **Create & Update:** Формы для добавления/редактирования (Название, Описание, Цена, Загрузка фото).
- **Read:** Табличное отображение с пагинацией.
- **Delete (Soft Delete):** Во избежание поломки истории старых заказов, товары не удаляются из БД физически. Вместо этого меняется флаг `isActive: false`, скрывая товар с витрины.

### Механизм уведомления о заказах

1.  Покупатель отправляет форму из виджета корзины.
2.  Next.js API Route формирует записи в таблицах `Order` и `OrderItem` (PostgreSQL).
3.  Сервер асинхронно отправляет HTTP-запрос к Telegram Bot API.
4.  Администратор получает push-уведомление в Telegram с деталями заказа (Сумма, Контакты, Состав заказа) для оперативной связи с клиентом.

## 🚀 6. Дополнительные опции (Масштабирование)

Архитектура проекта позволяет в будущем внедрить:

- **Личный кабинет клиента:** Интеграция OAuth (Google/Apple), сохранение истории заказов, привязка корзины к профилю (БД) вместо LocalStorage.
- **Расширенная навигация:** Внедрение системы категорий, тегов и клиентской фильтрации по цене/характеристикам.
- **Онлайн-оплата:** Интеграция платежных шлюзов (Stripe / LiqPay).

## 🎨 7. Визуальные референсы

- **Витрина:** Минимализм в стиле D2C-брендов (много белого пространства, крупные фото, залипающий хедер).
- **Корзина:** Классический паттерн Shopify (чистый Drawer, затемняющий основной контент).
- **Админка:** Строгий технический дизайн в стиле Vercel Dashboard или Tailwind UI (плотная сетка данных, темный сайдбар навигации).

**⚠️ Тут как будто немного не хватает деталей реализации (описание словами, не псевдокодом), но на данном этапе не страшно.**
