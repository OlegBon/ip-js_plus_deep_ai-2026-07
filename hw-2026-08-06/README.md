# Документація проєкту «Convertly Hub» (етап дизайну)

Цей каталог містить усю проєктну документацію, пов'язану з архітектурою та дизайном SaaS-платформи «Convertly Hub».

## Опис файлів

| Файл | Опис | Статус |
| :--- | :--- | :--- |
| `DESIGN.md` | **Основний і фінальний документ дизайн-системи.** Містить усі затверджені компоненти, токени, відступи та гайдлайни для розробки UI. | **Актуальний** |
| `architecture.md` | Описує високорівневу архітектуру застосунку, зокрема взаємодію клієнтської та серверної частин, бази даних і воркерів. | Актуальний |
| `tech_saas.md` | Докладна технічна специфікація продукту, бізнес-логіка, стек технологій і користувацькі сценарії. | Актуальний |
| `spec.md` | Вихідні вимоги та специфікації для розробки дизайн-системи. | Архівний |
| `DESIGN_1.md` | Варіант №1 дизайн-системи (мінімалістичний, на основі Vercel). | Варіант |
| `DESIGN_2.md` | Варіант №2 дизайн-системи (складніший, на основі Pirsch). **Став основою для `DESIGN.md`**. | Варіант |
| `DESIGN_3.md` | Варіант №3 дизайн-системи (альтернативний). | Варіант |
| `DESIGN_4.md` | Варіант №4 дизайн-системи (альтернативний). | Варіант |
| `DESIGN-Vercel.md` | Референс-аналіз дизайну Vercel. | Референс |
| `DESIGN-Pirsch_Analytics.md` | Референс-аналіз дизайну Pirsch Analytics. | Референс |
| `README.md` | Цей файл. | Мета |

**Основний робочий файл — `DESIGN.md`. Усі інші файли `DESIGN_*.md` є проміжними варіантами або референсами.**
