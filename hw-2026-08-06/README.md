# hw-2026-08-06 - Обзор файлов проекта

Этот каталог содержит различные документы, относящиеся к дизайну и архитектуре проекта "Convertly Hub".

## Файлы в этом каталоге:

- `architecture.md`: Описывает высокоуровневую архитектуру приложения.
- `tech_saas.md`: Детализирует технические аспекты и цели SaaS-платформы.
- `spec.md`: Предоставляет спецификацию для файлов `DESIGN.md`, включая формат и схему.
- `DESIGN-Vercel.md`: Справочный документ, демонстрирующий стиль дизайна Vercel.
- `DESIGN-Pirsch_Analytics.md`: Справочный документ, демонстрирующий стиль дизайна Pirsch Analytics.
- `DESIGN_1.md`: Исходный документ по дизайну для Convertly Hub.
- `DESIGN_2.md`: Уточненный, минималистичный документ по дизайну для Convertly Hub.

## Разбивка дизайн-документов:

| Имя файла     | Основан на                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| :------------ | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `DESIGN_1.md` | `architecture.md`, `tech_saas.md` и `spec.md` (для формата) - **агент**. Данная версия станет прямым воплощением технических и архитектурных требований проекта.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `DESIGN_2.md` | `DESIGN_1.md`, с дополнительными принципами минималистичного дизайна из `DESIGN-Vercel.md` и `DESIGN-Pirsch_Analytics.md` - **агент**. Эта версия станет усовершенствованной версией первой, в которой будут воплощены принципы минималистичного и лаконичного дизайна. Позволит создать более отточенный и стилизованный дизайн. Эта версия будет в значительной степени отражать минималистичную эстетику Vercel, ориентированную на разработчиков: в ней будет использоваться строгая монохромная палитра, четкая геометрия и подход к иерархии, в котором приоритет отдается типографике, при этом для обозначения основных действий будет использоваться один яркий акцентный цвет. |
| `DESIGN_3.md` | `architecture.md`, `tech_saas.md` и `spec.md` (для формата). Он строится строго по стандарту из спецификации, опираясь исключительно на заложенные тобой архитектурные и продуктовые требования. В этом варианте мы фиксируем использование Shadcn UI и Tailwind CSS, монохромную палитру с одним акцентом (глубокий синий или фиолетовый) и фокус на детальной проработке состояний Drag & Drop элементов.                                                                                                                                                                                                                                                                              |
| `DESIGN_4.md` | `DESIGN_1.md`, с дополнительными принципами минималистичного дизайна из `DESIGN-Vercel.md` и `DESIGN-Pirsch_Analytics.md`. Мы отказываемся от теней и лишних визуальных эффектов. Интерфейс будет выглядеть как распечатанный терминал разработчика или технический блокнот: теплый кремовый фон, контрастный почти черный текст, моноширинные шрифты для метаданных и тонкие 1px границы для карточек.                                                                                                                                                                                                                                                                                  |
