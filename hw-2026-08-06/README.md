# Документация проекта "Convertly Hub" (Этап Дизайна)

Этот каталог содержит всю проектную документацию, связанную с архитектурой и дизайном SaaS-платформы "Convertly Hub".

## Описание файлов

| Файл | Описание | Статус |
| :--- | :--- | :--- |
| `DESIGN.md` | **Основной и финальный документ дизайн-системы.** Содержит все утвержденные компоненты, токены, отступы и гайдлайны для разработки UI. | **Актуальный** |
| `architecture.md` | Описывает высокоуровневую архитектуру приложения, включая взаимодействие клиентской и серверной частей, базы данных и воркеров. | Актуальный |
| `tech_saas.md` | Детальная техническая спецификация продукта, бизнес-логика, стек технологий и пользовательские сценарии. | Актуальный |
| `spec.md` | Исходные требования и спецификации для разработки дизайн-системы. | Архивный |
| `DESIGN_1.md` | Вариант №1 дизайн-системы (Минималистичный, на основе Vercel). | Вариант |
| `DESIGN_2.md` | Вариант №2 дизайн-системы (Более сложный, на основе Pirsch). **Послужил основой для `DESIGN.md`**. | Вариант |
| `DESIGN_3.md` | Вариант №3 дизайн-системы (Альтернативный). | Вариант |
| `DESIGN_4.md` | Вариант №4 дизайн-системы (Альтернативный). | Вариант |
| `DESIGN-Vercel.md` | Референс-анализ дизайна Vercel. | Референс |
| `DESIGN-Pirsch_Analytics.md` | Референс-анализ дизайна Pirsch Analytics. | Референс |
| `README.md` | Этот файл. | Мета |

**Основной рабочий файл — `DESIGN.md`. Все остальные `DESIGN_*.md` файлы являются промежуточными вариантами или референсами.**
