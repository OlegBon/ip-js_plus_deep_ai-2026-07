# Домашнее задание 2026-08-06

Этот каталог содержит файлы, описывающие архитектуру и дизайн-систему для SaaS-проекта.

## Описание файлов

| Файл | Описание |
| :--- | :--- |
| `architecture.md` | Описывает высокоуровневую архитектуру SaaS-приложения, включая фронтенд, бэкенд, базу данных и аутентификацию. |
| `tech_saas.md` | Определяет технологический стек, который будет использоваться для реализации проекта. |
| `spec.md` | Содержит спецификации и требования к дизайн-системе. |
| `DESIGN-Vercel.md` | Пример-вдохновение: анализ ключевых элементов дизайн-системы Vercel. |
| `DESIGN-Pirsch_Analytics.md` | Пример-вдохновение: анализ ключевых элементов дизайн-системы Pirsch Analytics. |
| `DESIGN_1.md` | **Основа:** Минималистичная дизайн-система, созданная на базе `architecture.md` и `tech_saas.md` с учётом `spec.md`. |
| `DESIGN_2.md` | **Расширение:** Улучшенная версия `DESIGN_1.md` с добавлением семантических цветов и более сложных компонентов, вдохновляясь `Vercel` и `Pirsch`. |
| `DESIGN_3.md` | **Тёмная тема:** Адаптация дизайн-системы для тёмного режима отображения. |
| `DESIGN_4.md` | **Дашборд:** Специализированные компоненты для визуализации данных (графики, таблицы). |
