# Дизайн-система: Темна тема

Цей документ описує адаптацію дизайн-системи для темної теми зі збереженням мінімалізму та читабельності.

## Design Philosophy (Філософія дизайну)

- **Контрастність**: Достатній контраст для комфортного читання за слабкого освітлення (WCAG AA).
- **Глибина**: Використання різних відтінків сірого для створення ієрархії та глибини інтерфейсу.
- **Акценти**: Яскраві акценти мають залишатися помітними, але не засліплювати.

## Layout (Макет)

Структура макета й система відступів залишаються ідентичними світлій темі для забезпечення послідовності.

## Tokens (Токени)

Кольорові токени перевизначаються для темного режиму. Інші токени (типографіка, відступи) успадковуються.

## Surfaces (Поверхні)

У темній темі поверхні визначаються переважно через 미묘한 (subtle) зміни кольору фону та рамок.

- **Основний фон**: `var(--color-background)` — глибокий сірий, близький до чорного.
- **Картки та панелі**: `var(--color-background-secondary)` — світліший відтінок сірого, щоб «підняти» їх над основним фоном.
- **Тіні**: Тіні не використовуються. Замість них для виділення використовується `border: 1px solid var(--color-border)`.

## Imagery (Зображення)

- **Іконки**: Зберігають свій стиль, але їхній колір інвертується відповідно до текстових токенів.
- **Зображення та ілюстрації**: Слід зменшити яскравість і контрастність зображень на 10–20%, щоб вони не «вибивалися» з темного оточення. Можна використовувати CSS-фільтр `filter: brightness(.9)`.

## Do's and Don'ts (Що робити й чого не робити)

### Do's (Що робити)
- **Перевіряйте контрастність**: Переконайтеся, що контраст між текстом і фоном відповідає стандартам WCAG (мінімум 4.5:1).
- **Використовуйте приглушені кольори**: Чистий чорний (`#000`) фон може спричиняти втому очей. Краще використовувати темно-сірий (`#121212`).
- **Тестуйте на реальних пристроях**: Перевіряйте, як тема виглядає за різного освітлення.

### Don'ts (Чого не робити)
- **Не використовуйте чистий білий текст на чорному фоні**: Це створює надто високий контраст. Використовуйте світло-сірі відтінки (`#E5E5E5`).
- **Не інвертуйте зображення**: Проста інверсія кольорів спотворює фотографії та ілюстрації. Краще підготуйте окремі асети або використовуйте CSS-фільтри.
- **Не покладайтеся лише на колір**: Використовуйте іконки, текст або інші індикатори для передавання важливої інформації, а не лише колір, який може змінюватися.

## Quick Start (Швидкий старт)

```css
/* 1. Токени для темної теми */
/* 
  Можно применять автоматически через медиа-запрос 
  или вручную, добавляя класс .dark к <body> 
*/
@media (prefers-color-scheme: dark) {
  :root {
    --color-background: #121212;
    --color-background-secondary: #1E1E1E;
    --color-text-primary: #E5E5E5;
    --color-text-secondary: #A3A3A3;
    --color-accent: #5E9DFF;
    --color-accent-hover: #80BFFF;
    --color-border: #2C2C2C;

    --color-success: #34D399;
    --color-error: #F87171;
    --color-warning: #FBBF24;
  }
}

.dark {
  --color-background: #121212;
  --color-background-secondary: #1E1E1E;
  --color-text-primary: #E5E5E5;
  --color-text-secondary: #A3A3A3;
  --color-accent: #5E9DFF;
  --color-accent-hover: #80BFFF;
  --color-border: #2C2C2C;

  --color-success: #34D399;
  --color-error: #F87171;
  --color-warning: #FBBF24;
}

/* 2. Адаптація компонентів для темної теми */

/* Кнопки */
.dark .btn-primary {
  background-color: var(--color-accent);
  color: var(--color-background); /* Зміна кольору тексту на темний */
}
.dark .btn-primary:hover {
  background-color: var(--color-accent-hover);
}

.dark .btn-secondary {
  background-color: var(--color-background-secondary);
  border-color: var(--color-border);
  color: var(--color-text-primary);
}
.dark .btn-secondary:hover {
  background-color: #333333;
}

/* Карточки */
.dark .card {
  background-color: var(--color-background-secondary);
  border-color: var(--color-border);
  box-shadow: none; /* Убираем тень */
}

/* Изображения */
.dark img, .dark svg {
  filter: brightness(.9);
}
```
