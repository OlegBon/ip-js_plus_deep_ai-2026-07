# Дизайн-система: Тёмная тема

Этот документ описывает адаптацию дизайн-системы для тёмной темы, сохраняя минимализм и читаемость.

## Design Philosophy (Философия дизайна)

- **Контрастность**: Достаточный контраст для комфортного чтения в условиях низкой освещенности (WCAG AA).
- **Глубина**: Использование разных оттенков серого для создания иерархии и глубины интерфейса.
- **Акценты**: Яркие акценты должны оставаться заметными, но не ослепляющими.

## Layout (Макет)

Структура макета и система отступов остаются идентичными светлой теме для обеспечения консистентности.

## Tokens (Токены)

Цветовые токены переопределяются для тёмного режима. Остальные токены (типографика, отступы) наследуются.

## Surfaces (Поверхности)

В тёмной теме поверхности определяются в основном через 미묘한 (subtle) изменения цвета фона и рамок.

- **Основной фон**: `var(--color-background)` — глубокий серый, близкий к черному.
- **Карточки и панели**: `var(--color-background-secondary)` — более светлый оттенок серого, чтобы "приподнять" их над основным фоном.
- **Тени**: Тени не используются. Вместо них для выделения используется `border: 1px solid var(--color-border)`.

## Imagery (Изображения)

- **Иконки**: Сохраняют свой стиль, но их цвет инвертируется в соответствии с текстовыми токенами.
- **Изображения и иллюстрации**: Следует уменьшить яркость и контрастность изображений на 10-20%, чтобы они не "выбивались" из тёмного окружения. Можно использовать CSS-фильтр `filter: brightness(.9)`.

## Do's and Don'ts (Что делать и чего не делать)

### Do's (Что делать)
- **Проверяйте контрастность**: Убедитесь, что контраст между текстом и фоном соответствует стандартам WCAG (минимум 4.5:1).
- **Используйте приглушенные цвета**: Чистый черный (`#000`) фон может вызывать усталость глаз. Предпочтительнее тёмно-серый (`#121212`).
- **Тестируйте на реальных устройствах**: Проверяйте, как тема выглядит при разном освещении.

### Don'ts (Чего не делать)
- **Не используйте чистый белый текст на черном фоне**: Это создает слишком высокий контраст. Используйте светло-серые оттенки (`#E5E5E5`).
- **Не инвертируйте изображения**: Простая инверсия цветов искажает фотографии и иллюстрации. Лучше подготовьте отдельные ассеты или используйте CSS-фильтры.
- **Не полагайтесь только на цвет**: Используйте иконки, текст или другие индикаторы для передачи важной информации, а не только цвет, который может меняться.

## Quick Start (Быстрый старт)

```css
/* 1. Токены для тёмной темы */
/* 
  Можно применять автоматически через медиа-запрос 
  или вручную, добавляя класс .dark к <body> 
*/
@media (prefers-color-scheme: dark) {
  :root {
    --color-background: #121212;
    --color-background-secondary: #1E1E1E;
    --color-text-primary: #E5E5E5;
    --color-text-secondary: #A3A3A3;
    --color-accent: #5E9DFF;
    --color-accent-hover: #80BFFF;
    --color-border: #2C2C2C;

    --color-success: #34D399;
    --color-error: #F87171;
    --color-warning: #FBBF24;
  }
}

.dark {
  --color-background: #121212;
  --color-background-secondary: #1E1E1E;
  --color-text-primary: #E5E5E5;
  --color-text-secondary: #A3A3A3;
  --color-accent: #5E9DFF;
  --color-accent-hover: #80BFFF;
  --color-border: #2C2C2C;

  --color-success: #34D399;
  --color-error: #F87171;
  --color-warning: #FBBF24;
}

/* 2. Адаптация компонентов для тёмной темы */

/* Кнопки */
.dark .btn-primary {
  background-color: var(--color-accent);
  color: var(--color-background); /* Изменение цвета текста на темный */
}
.dark .btn-primary:hover {
  background-color: var(--color-accent-hover);
}

.dark .btn-secondary {
  background-color: var(--color-background-secondary);
  border-color: var(--color-border);
  color: var(--color-text-primary);
}
.dark .btn-secondary:hover {
  background-color: #333333;
}

/* Карточки */
.dark .card {
  background-color: var(--color-background-secondary);
  border-color: var(--color-border);
  box-shadow: none; /* Убираем тень */
}

/* Изображения */
.dark img, .dark svg {
  filter: brightness(.9);
}
```
