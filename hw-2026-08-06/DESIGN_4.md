# Дизайн-система: Аналітична панель (Dashboard)

Ця частина системи зосереджена на візуалізації даних: графіках, таблицях і ключових метриках.

## Design Philosophy (Філософія дизайну)

- **Наочність**: Дані мають бути зрозумілими з першого погляду.
- **Щільність інформації**: Баланс між кількістю даних на екрані та їхньою читабельністю.
- **Інтерактивність**: Користувач може легко фільтрувати, сортувати й досліджувати дані.

## Layout (Макет дашборду)

- **Сітка**: Використовується CSS Grid (`grid-template-columns: repeat(auto-fit, minmax(300px, 1fr))`) для гнучкого розташування віджетів.
- **Віджети**: Кожен віджет — це картка (`Surfaces`) із заголовком, що містить графік, таблицю або ключову метрику (KPI).
- **Адаптивність**: На мобільних пристроях віджети вибудовуються в одну колонку.

## Tokens (Токени)

Додаються спеціальні токени для візуалізації даних.

### Data Colors (Кольори для даних)

## Surfaces (Поверхні)

- **Віджети (Widgets)**: Є основним типом поверхні на дашборді. Це картки, що можуть містити графіки, таблиці або KPI. Вони використовують `--color-background-secondary` і мають `padding: var(--space-lg)`.
- **Спливні підказки (Tooltips)**: Поверхні, що з’являються при наведенні на елементи даних. Мають темний фон (`#1F2937`) і світлий текст для контрасту.

## Components (Компоненти для даних)

### Таблиці
Таблиці оптимізовано для сканування.

### Фільтри та селектори дат
- **Селектор діапазону дат**: Дає змогу вибрати попередньо встановлені (`Сьогодні`, `Останні 7 днів`) або довільні діапазони.
- **Фільтри**: Кнопки-теги, які можна активувати/деактивувати для фільтрації даних у реальному часі.

## Imagery (Зображення)

- **Графіки**: Лінійні графіки, стовпчикові діаграми, кругові діаграми. Лінії мають бути товщиною `2px`.
- **Порожні стани**: Якщо даних для відображення немає, віджет має показувати ілюстрацію та повідомлення (наприклад, «Немає даних за вибраний період»).

## Do's and Don'ts (Що робити й чого не робити)

### Do's (Що робити)
- **Підписуйте осі**: Завжди додавайте підписи до осей X і Y на графіках.
- **Використовуйте Tooltips**: Надавайте точні значення у спливних підказках при наведенні на графік.
- **Забезпечте стан завантаження**: Використовуйте скелетні екрани (skeletons) для віджетів під час завантаження даних.

### Don'ts (Чого не робити)
- **Не використовуйте надто багато кольорів**: В одному графіку не має бути понад 5–7 категорій, щоб уникнути візуального шуму.
- **Не перевантажуйте дашборд**: Надто багато віджетів на одному екрані ускладнює сприйняття. Групуйте пов’язану інформацію.
- **Не використовуйте 3D-графіки**: Вони спотворюють дані та ускладнюють порівняння значень.

## Quick Start (Швидкий старт)

```css
/* 1. Токени для даних */
:root {
  --color-data-1: #3B82F6; /* Синій */
  --color-data-2: #10B981; /* Зелений */
  --color-data-3: #F59E0B; /* Жовтий */
  --color-data-4: #EF4444; /* Червоний */
  --color-data-5: #8B5CF6; /* Фіолетовий */
}

/* 2. Макет дашборда */
.dashboard-grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(300px, 1fr));
  gap: var(--space-lg);
}

/* 3. Компоненти */

/* Таблиці */
.table {
  width: 100%;
  border-collapse: collapse;
}

.table th, .table td {
  padding: var(--space-sm) var(--space-md);
  text-align: left;
  border-bottom: 1px solid var(--color-border);
}

.table thead th {
  background-color: var(--color-background-secondary);
  font-weight: 600;
}

.table tbody tr:nth-child(even) {
  background-color: var(--color-background-secondary);
}

.table tbody tr:hover {
  background-color: #F0F0F0; /* Немного темнее для ховера */
}

/* Скелетні завантажувачі */
.skeleton {
  background-color: var(--color-background-secondary);
  border-radius: 4px;
  animation: pulse 1.5s infinite ease-in-out;
}

@keyframes pulse {
  0% {
    opacity: 1;
  }
  50% {
    opacity: 0.5;
  }
  100% {
    opacity: 1;
  }
}
```
