# Локальные правила: База данных

Применяйте эти правила при изменении Prisma-схемы, миграций, SQL или server-side доступа к PostgreSQL.

1. Прочитайте `database-migrations` для изменений схемы и миграций, `prisma-patterns` для Prisma Client и `postgres-patterns` для SQL, индексов и производительности.
2. Не запускайте команды, меняющие БД, без явного разрешения пользователя; `prisma migrate reset` не используйте вне одноразовой локальной базы разработки.
3. Не раскрывайте строки подключения и другие секреты.
4. При изменении схемы обновляйте `docs/db-schema.md`, при изменении потоков данных — `docs/architecture.md`, а результаты проверок фиксируйте в `docs/progress.md`.
