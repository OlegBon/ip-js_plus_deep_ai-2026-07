# Локальные правила: Качество и Производительность

## 1. Качество дизайна (Anti-Template Policy)

Нельзя создавать общий, "шаблонный" UI. Интерфейс должен выглядеть продуманным и соответствовать продукту.

### Запрещенные паттерны

-   Стандартные сетки карточек без иерархии.
-   Типичная "hero" секция с заголовком по центру.
-   Плоский дизайн без ощущения глубины или слоев.
-   Скучная серо-белая палитра с одним акцентным цветом.

### Требуемые качества

Каждый значимый элемент интерфейса должен демонстрировать как минимум **четыре** из этих качеств:

1.  **Четкая иерархия** через контраст размеров.
2.  **Продуманный ритм** в отступах, а не одинаковые `padding` везде.
3.  **Глубина или слоистость** через наложение, тени или анимацию.
4.  **Характерная типографика** с осмысленной парой шрифтов.
5.  **Цвет**, используемый семантически, а не просто для украшения.
6.  **Продуманные состояния** `:hover`, `:focus`, и `:active`.
7.  **Асимметричные или "bento" сетки**, где это уместно.
8.  **Движение (motion)**, которое поясняет, а не отвлекает.

## 2. Веб-производительность

### Целевые показатели Core Web Vitals

| Метрика | Цель   |
| ------- | ------ |
| LCP     | < 2.5с |
| INP     | < 200мс|
| CLS     | < 0.1  |

### Бюджеты на загрузку

| Тип страницы      | JS (gzipped) | CSS (gzipped) |
| ----------------- | ------------ | ------------- |
| Лендинг           | < 150kb      | < 30kb        |
| Страница в приложении | < 300kb      | < 50kb        |

### Стратегия загрузки

1.  **Критический CSS:** Встраивай (inline) CSS для первого экрана, где это оправдано.
2.  **Приоритет загрузки:** Используй `fetchpriority="high"` для главного изображения (LCP) и основного шрифта.
3.  **Ленивая загрузка:** Используй `loading="lazy"` для всех изображений ниже первого экрана.
4.  **Динамический импорт:** Подгружай тяжелые библиотеки динамически, когда они действительно нужны.

    ```js
    const heavyLibrary = await import('some-heavy-library');
    ```

### Оптимизация изображений

-   Всегда указывай `width` и `height` для `<img>`, чтобы избежать сдвигов макета (CLS).
-   Предпочитай современные форматы, такие как **AVIF** или **WebP**.

### Оптимизация анимаций

-   Анимируй только `transform`, `opacity` и `clip-path`.
-   Избегай анимации свойств, влияющих на геометрию (layout): `width`, `height`, `margin`, `padding`, `top`, `left`.
