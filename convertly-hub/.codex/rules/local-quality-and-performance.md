# Локальні правила: якість і продуктивність

## 1. Якість дизайну (Anti-Template Policy)

Не можна створювати загальний «шаблонний» UI. Інтерфейс має виглядати продуманим і відповідати продукту.

### Заборонені патерни

-   Стандартні сітки карток без ієрархії.
-   Типова «hero»-секція із заголовком по центру.
-   Плаский дизайн без відчуття глибини або шарів.
-   Нудна сіро-біла палітра з одним акцентним кольором.

### Необхідні якості

Кожен значущий елемент інтерфейсу має демонструвати щонайменше **чотири** з цих якостей:

1.  **Чітка ієрархія** через контраст розмірів.
2.  **Продуманий ритм** у відступах, а не однаковий `padding` усюди.
3.  **Глибина або шаруватість** через накладання, тіні чи анімацію.
4.  **Характерна типографіка** з осмисленою парою шрифтів.
5.  **Колір**, використаний семантично, а не лише для оздоблення.
6.  **Продумані стани** `:hover`, `:focus` і `:active`.
7.  **Асиметричні або «bento»-сітки**, де це доречно.
8.  **Рух (motion)**, який пояснює, а не відволікає.

## 2. Вебпродуктивність

### Цільові показники Core Web Vitals

| Метрика | Цель   |
| ------- | ------ |
| LCP     | < 2.5с |
| INP     | < 200мс|
| CLS     | < 0.1  |

### Бюджети завантаження

| Тип сторінки      | JS (gzipped) | CSS (gzipped) |
| ----------------- | ------------ | ------------- |
| Лендинг           | < 150kb      | < 30kb        |
| Сторінка в застосунку | < 300kb      | < 50kb        |

### Стратегія завантаження

1.  **Критичний CSS:** вбудовуй (inline) CSS для першого екрана, де це виправдано.
2.  **Пріоритет завантаження:** використовуй `fetchpriority="high"` для головного зображення (LCP) та основного шрифту.
3.  **Ліниве завантаження:** використовуй `loading="lazy"` для всіх зображень нижче першого екрана.
4.  **Динамічний імпорт:** довантажуй важкі бібліотеки динамічно, коли вони справді потрібні.

    ```js
    const heavyLibrary = await import('some-heavy-library');
    ```

### Оптимізація зображень

-   Завжди вказуй `width` і `height` для `<img>`, щоб уникнути зсувів макета (CLS).
-   Надавай перевагу сучасним форматам, таким як **AVIF** або **WebP**.

### Оптимізація анімацій

-   Анімуй лише `transform`, `opacity` і `clip-path`.
-   Уникай анімації властивостей, що впливають на геометрію (layout): `width`, `height`, `margin`, `padding`, `top`, `left`.
