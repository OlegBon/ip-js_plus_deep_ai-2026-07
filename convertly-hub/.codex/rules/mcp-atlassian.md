# Правила використання MCP: Atlassian

## Сценарії використання

Інструменти `Atlassian` (Teamwork Graph) використовуються для отримання інформації про зв'язки між сутностями Atlassian (Jira, Confluence) та іншими інструментами.

## Типові завдання

- **Пошук пов'язаних завдань:** коли потрібно зрозуміти, які завдання Jira пов'язані з певним проєктом, епіком або спринтом. (`getTeamworkGraphContext`)
- **Пошук відповідальних:** знайти відповідального за компонент, проєкт або завдання. (`getTeamworkGraphContext` з `targetObjectTypes=["AtlassianUser"]`)
- **Отримання подробиць:** після знаходження потрібних об'єктів (завдань, сторінок) через `getTeamworkGraphContext` використовуй `getTeamworkGraphObject`, щоб отримати їх повний вміст (опис, статус, коментарі).

## Алгоритм дослідження

1.  **Визнач точку входу:** почни з відомої тобі сутності (наприклад, тікета Jira `PROJ-123` або сторінки Confluence).
2.  **Запитай контекст:** використай `getTeamworkGraphContext`, указавши `objectType` та `objectIdentifier`. Ти можеш фільтрувати зв'язки за `relationshipTypes` або `targetObjectTypes` для точнішого пошуку.
3.  **Отримай ARI:** з відповіді `getTeamworkGraphContext` отримай ARI (Atlassian Resource Identifiers) пов'язаних об'єктів, які тебе цікавлять.
4.  **Отримай подробиці:** передай ці ARI до `getTeamworkGraphObject`, щоб завантажити повну інформацію про них.
5.  **Проаналізуй і дай відповідь:** на основі отриманих даних дай користувачеві відповідь на його запитання (наприклад, «Завдання `PROJ-123` блокує тікет `PROJ-456`, що має статус 'In Review'»).
