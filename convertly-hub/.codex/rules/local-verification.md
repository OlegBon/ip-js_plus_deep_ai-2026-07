# Проверка изменений

После изменения исходного кода, конфигурации или зависимостей выполните проверки, применимые к задаче:

```bash
npm run linteslint
npm run test
npm run build
```
Если production—сборка в песочнице не проходит из-за ограничения Turbopack/PostCSS на локальный порт, запросите разрешение на запуск вне песочницы и сообщите итог проверки.

Не заявляйте об успешной сборке, если команда не была выполнена или завершилась с ошибкой.
