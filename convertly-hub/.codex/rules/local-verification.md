# Перевірка змін

Після зміни вихідного коду, конфігурації або залежностей виконайте перевірки, що стосуються завдання:

```bash
npm run linteslint
npm run test
npm run build
```
Якщо production-збірка в пісочниці не проходить через обмеження Turbopack/PostCSS на локальний порт, запросіть дозвіл на запуск поза пісочницею та повідомте результат перевірки.

Не заявляйте про успішну збірку, якщо команду не виконано або вона завершилася з помилкою.
