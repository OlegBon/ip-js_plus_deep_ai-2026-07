# Локальні правила: фінанси

## 1. Точність обчислень

- **Жодних наближень:** будь-які функції, пов'язані з фінансовими обчисленнями (розрахунок вартості, відсотків, конвертація валют), мають суворо відповідати загальноприйнятим стандартам. Заборонено використовувати неточні округлення або допуски.
- **Уникай `float`:** для роботи з грошима **уникай** використання стандартних чисел із плаваючою комою (`number` у JavaScript/TypeScript), оскільки це може призвести до помилок точності.

## 2. Правильні типи даних

- **Цілочислові значення:** зберігай та обробляй грошові значення як цілі числа (у мінімальних одиницях, наприклад у копійках або центах).
- **Бібліотеки для грошей:** якщо потрібна складна логіка, використовуй перевірені бібліотеки для роботи з грошовими значеннями, такі як `dinero.js` або `big.js`, щоб уникнути проблем із точністю.
