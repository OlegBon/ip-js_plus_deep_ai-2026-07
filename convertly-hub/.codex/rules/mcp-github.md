# Правила використання MCP: GitHub

## Сценарії використання

Інструменти `GitHub` слід використовувати для завдань, пов'язаних із керуванням кодом і взаємодією з репозиторієм.

## Типові завдання

- **Пошук коду (`search_code`):** використовуй для пошуку прикладів реалізації, наявних функцій або використання певних змінних у всьому репозиторії.
- **Робота з Issues (`create_issue`, `list_issues`, `get_issue`):** використовуй для створення звітів про помилки або запитів на нові функції, а також для отримання інформації про наявні завдання.
- **Робота з Pull Requests (`create_pull_request`, `list_pull_requests`, `get_pull_request_files`):** використовуй для створення, перегляду та аналізу Pull Request.
- **Читання файлів (`get_file_contents`):** використовуй для отримання вмісту файлів із репозиторію, коли локальне читання недоступне або незручне.

## Алгоритм дій під час роботи з кодом

1.  **Зрозумій завдання:** чітко визнач, що потрібно зробити (наприклад, «створити PR із виправленням бага X»).
2.  **Збери інформацію:** використовуй `search_code` або `get_file_contents` для аналізу поточного стану коду.
3.  **Внеси зміни (локально):** використовуй `write_file` або `replace` для зміни локальних файлів.
4.  **Створи Pull Request:** якщо потрібно, використовуй `create_pull_request`, щоб запропонувати зміни для merge. Обов'язково надай чіткий опис змін у тілі PR.
