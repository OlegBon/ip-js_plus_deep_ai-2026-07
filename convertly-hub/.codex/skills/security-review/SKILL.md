# Цель навыка

Провести серию автоматизированных и полуавтоматизированных проверок для выявления распространенных уязвимостей в коде проекта.

# Триггеры активации

Активируй, если пользователь просит: "проверь безопасность", "сделай аудит безопасности", "найди уязвимости".

# Инструкции по выполнению

Действуй строго по шагам, используя инструменты для анализа кода.

## Шаг 1: Проверка зависимостей

Используй `run_shell_command` для запуска команды `npm audit`. Это поможет выявить уязвимости в используемых библиотеках.

- **Команда:** `npm audit`
- **Что искать:** Наличие уязвимостей (vulnerabilities). Если найдены, сообщи их количество и уровень критичности.

## Шаг 2: Поиск жестко закодированных секретов

Используй `grep_search` для поиска потенциальных ключей API, паролей или других секретов, оставленных в коде.

- **Паттерн для поиска:** `(sk-proj-|password|secret|token|key)[=:]\s*['"]`
- **Что искать:** Любые совпадения, которые выглядят как учетные данные. Исключи файлы `.md` и `package-lock.json` из поиска.

## ШаГ 3: Анализ Prisma Schema

Прочитай файл `prisma/schema.prisma` и проверь базовые аспекты безопасности.

- **Файл:** `prisma/schema.prisma`
- **Что искать:**
    1. Убедись, что поле `password` в модели `User` имеет тип `String` и не имеет значений по умолчанию.
    2. Проверь, что для чувствительных данных не используются непредназначенные для этого типы.

## Шаг 4: Анализ API маршрутов

Проверь существующие API-маршруты на предмет базовой валидации.

- **Директория:** `app/api/`
- **Что искать:**
    1. Есть ли какая-либо валидация входящих данных (например, с использованием `zod` или ручных проверок)?
    2. Используются ли параметризованные запросы к базе данных (Prisma Client по умолчанию делает это)?

# Формат вывода

Сформируй отчет в формате Markdown, обобщая результаты каждого шага:

1.  **Аудит зависимостей:** (Результат `npm audit`)
2.  **Поиск секретов:** (Найдены или не найдены совпадения)
3.  **Анализ Prisma Schema:** (Замечания по схеме)
4.  **Анализ API маршрутов:** (Замечания по коду API)

Заверши свой ответ строго фразой: _"Аудит безопасности завершен. Жду дальнейших указаний."_
