# Схема бази даних

Документ описує Prisma-схему Convertly Hub для PostgreSQL. У репозиторії є міграції `20260824093000_rbac_telegram` для RBAC/Telegram, `20260825090000_subscription_quotas` для тарифів і квот, `20260826120000_quota_reservations` для атомарного резервування місця у сховищі, `20260831110000_conversion_result_reuse` для безпечного повторного використання не спливлого результату та `20260907170000_telegram_password_recovery` для unique public Telegram username. У новому оточенні перед використанням Telegram, тарифів або конвертації застосуйте всі міграції командою `npx prisma migrate deploy`.

## Перелічення

| Перелічення                | Значення                                                      | Призначення                                                |
| -------------------------- | ------------------------------------------------------------- | ---------------------------------------------------------- |
| `UserRole`                 | `USER`, `ADMIN`                                               | Доступ до користувацьких та адміністративних дій.          |
| `UserStatus`               | `ACTIVE`, `SUSPENDED`                                         | Блокування облікового запису без його видалення.           |
| `SubscriptionPlan`         | `FREE`, `BASIC`, `PRO`, `ENTERPRISE`                          | Активний або очікуваний тариф.                             |
| `SubscriptionStatus`       | `ACTIVE`, `PENDING_DEMO`                                      | Активна підписка або єдина очікувана demo-заявка.          |
| `ConversionStatus`         | `PENDING`, `PROCESSING`, `COMPLETED`, `FAILED`                | Стан обробки файлу.                                        |
| `AccountDeletionStatus`    | `PENDING`, `PROCESSING`, `COMPLETED`, `FAILED`, `CANCELLED`   | Стан користувацького запиту на видалення облікового запису. |
| `AccountDeletionEventType` | `REQUESTED`, `PROCESSING`, `COMPLETED`, `FAILED`, `CANCELLED` | Тип незмінної події audit trail видалення.                  |

## Моделі

### `User`

Користувач, його налаштування, стан доступу та зв'язки з ключами/конвертаціями.

| Поле                     | Тип                     | Обмеження та призначення                                                                                                                                                                                            |
| ------------------------ | ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `id`                     | `String`                | Первинний ключ, UUID.                                                                                                                                                                                              |
| `email`                  | `String`                | Обов'язкове унікальне значення; лишається чинним до підтвердження заміни.                                                                                                                                           |
| `pendingEmail`           | `String?`               | Необов'язкове унікальне нове значення email до підтвердження одноразовим посиланням.                                                                                                                               |
| `password`               | `String`                | Обов'язковий хеш пароля; відкритий пароль не зберігається.                                                                                                                                                          |
| `role`                   | `UserRole`              | Обов'язкове, за замовчуванням `USER`.                                                                                                                                                                               |
| `status`                 | `UserStatus`            | Обов'язкове, за замовчуванням `ACTIVE`; індекс для адміністративної фільтрації.                                                                                                                                     |
| `storeConversions`       | `Boolean`               | Обязательная настройка хранения результатов, по умолчанию `true`.                                                                                                                                                  |
| auth і Telegram-поля     | `String?` / `DateTime?` | Хеші одноразових токенів, строки дії та дати підтвердження; `emailVerificationExpires` і `passwordResetExpires` надають reset-посиланням TTL 30 хвилин, а `telegramId` і нормалізований `telegramUsername` унікальні. |
| `apiKeys`, `conversions` | зв'язки                 | Один користувач має багато API-ключів і записів конвертацій.                                                                                                                                                       |
| `subscription`           | зв'язок `Subscription?` | One-to-one підписка; її `activePlan` — єдине джерело активного тарифу.                                                                                                                                              |

### `Subscription`

`id` — первинний UUID; `userId` — обов'язковий унікальний зовнішній ключ на `User` із каскадним видаленням. `activePlan` обов'язковий і має default `FREE`; `requestedPlan` необов'язковий і зберігає останню зміну; `status`, `createdAt` і `updatedAt` обов'язкові. Mock Checkout не зберігає поля форми або платіжні дані.

`Subscription.activePlan` — єдине джерело активного тарифу. Migration
`20260907140000_subscription_plan_source_of_truth` створює відсутні
subscriptions із legacy-плану та потім видаляє `User.plan`; у разі розходження
перемагає вже наявний `Subscription.activePlan`. До підключення справжнього
payment provider ручна підтримка використовує one-off
`scripts/sync-user-plan.mjs`: він змінює лише subscription, очищує
`requestedPlan` і переводить `status` у `ACTIVE`. Це операційний demo-інструмент,
а не заміна платіжному webhook.

### `GuestConversionQuota`

Місячний лічильник гостьового браузера. `id`, `visitorHash`, `periodStart`,
`imageCount`, `documentCount` і `updatedAt` — обов'язкові поля; первинний ключ
— UUID `id`. `visitorHash` — SHA-256 від HttpOnly visitor-cookie, а не сам cookie.
Складений unique index `[visitorHash, periodStart]` гарантує одну квоту на
браузер і календарний місяць.

### `AccountDeletionRequest` і `AccountDeletionEvent`

`AccountDeletionRequest` створюється лише автентифікованим активним користувачем і містить
snapshot `userEmail`, поточний `status`, моменти запиту/обробки/завершення/скасування, безпечну
причину помилки та snapshot адміністратора-обробника або користувача, що скасував запит. Nullable
унікальний `userId` допускає один
активний request на користувача та використовує `ON DELETE SET NULL`: після видалення `User` запис
запиту лишається для операційного аудиту, але більше не посилається на видалений обліковий запис.

`AccountDeletionEvent` — append-only події request із типом, часом і snapshot actor email.
Зв'язок із request каскадний. Індекси `[status, requestedAt]` і `[requestId, createdAt]` підтримують
чергу Admin Panel та перегляд audit trail. Міграція
`20260907150000_account_deletion_workflow` створює обидві моделі, а
`20260907160000_account_deletion_request_management` додає скасування. Повний порядок обробки та заходи
безпеки описано у [account-deletion-workflow.md](./account-deletion-workflow.md).

### `ApiKey`

Ключ публічного API. Секрет ключа зберігається лише у вигляді `keyHash`; `keyPrefix` призначений для безпечного відображення в UI.

| Поле                      | Тип         | Обмеження та призначення                                                                       |
| ------------------------- | ----------- | ---------------------------------------------------------------------------------------------- |
| `id`                      | `String`    | Первинний ключ, UUID.                                                                          |
| `name`                    | `String`    | Обов'язкове ім'я ключа, за замовчуванням `Default`.                                            |
| `keyHash`                 | `String`    | Обов'язкове унікальне SHA-256-значення для автентифікації; вихідний секрет у БД не зберігається. |
| `keyPrefix`               | `String`    | Несекретний префікс ключа для відображення.                                                    |
| `lastUsedAt`, `revokedAt` | `DateTime?` | Час останнього використання та відкликання ключа.                                              |
| `userId`                  | `String`    | Обов'язковий зовнішній ключ на `User`; під час видалення користувача ключ видаляється каскадно. |
| `conversions`             | зв'язок     | Конвертації, ініційовані цим ключем.                                                           |

Індекс `@@index([userId, revokedAt])` підтримує видачу активних ключів користувача.

### `RoleChangeAudit`

Незмінний запис про призначення першого адміністратора та подальші зміни ролей. `actorUserId` порожній лише в разі одноразового bootstrap-призначення, а `targetUserId`, стара й нова ролі записуються завжди. Індекси підтримують аудит за цільовим користувачем та ініціатором.

### `ConversionLog`

Метадані однієї конвертації. У БД не зберігаються бінарні файли: `storageKey` пов'язує збережений результат із S3-сумісним сховищем.

| Поле                                             | Тип                          | Обмеження та призначення                                                                                                                                                                                                                                       |
| ------------------------------------------------ | ---------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `id`                                             | `String`                     | Первинний ключ, UUID.                                                                                                                                                                                                                                          |
| `sourceFileName`, `sourceMimeType`, `sourceSize` | `String`, `String`, `BigInt` | Обов'язкові метадані вихідного файлу.                                                                                                                                                                                                                          |
| `sourceFileHash`                                 | `String?`                    | Необов'язковий SHA-256 хеш вмісту нових browser-конвертацій; використовується лише для пошуку вже доступного результату того самого користувача й не є файлом або секретом. Старі рядки не заповнюються, оскільки вихідні бінарні файли не зберігаються. |
| `targetFormat`                                   | `String`                     | Обов'язковий цільовий формат.                                                                                                                                                                                                                                  |
| `status`                                         | `ConversionStatus`           | Обов'язковий стан, за замовчуванням `PENDING`.                                                                                                                                                                                                                 |
| result-поля                                      | `String?` / `BigInt?`        | Метадані результату після успішної обробки.                                                                                                                                                                                                                    |
| `storageReservationBytes`                        | `BigInt?`                    | Коротке серверне резервування розміру результату під час `PROCESSING`; знімається за успішного запису до S3 або помилки.                                                                                                                                       |
| `storageKey`                                     | `String?`                    | Унікальний ключ об'єкта у S3; `null` для режиму без зберігання.                                                                                                                                                                                                |
| `errorMessage`                                   | `String?`                    | Контекст помилки конвертації без чутливих даних.                                                                                                                                                                                                                |
| lifecycle-поля                                   | `DateTime?`                  | Час старту, завершення та спливу тимчасового посилання.                                                                                                                                                                                                        |
| `userId`                                         | `String`                     | Обов'язковий зовнішній ключ на `User`; каскадне видалення записів під час видалення користувача.                                                                                                                                                               |
| `apiKeyId`                                       | `String?`                    | Необов'язковий зовнішній ключ на `ApiKey`; під час видалення ключа посилання стає `null`.                                                                                                                                                                      |

Індекси `@@index([userId, createdAt])`, `@@index([userId, sourceFileHash, targetFormat])`, `@@index([userId, expiresAt])`, `@@index([status, createdAt])` і `@@index([apiKeyId])` підтримують історію користувача, пошук доступного збіжного результату, розрахунок storage, обробку черги та аудит API-викликів.

Usage Dashboard рахує успішні конвертації поточного місяця та суму `resultSize` не спливлих або безстрокових рядків із `storageKey`; обхід S3 для кожного запиту не потрібен. Перед S3-upload сервер під PostgreSQL advisory lock резервує `storageReservationBytes`, тому паралельні воркери не можуть перевищити загальний storage-ліміт. `expiresAt` фіксується під час завершення за активним на той момент тарифом.

## Час і застосування міграцій

Усі часові поля зберігаються в PostgreSQL як `timestamptz(3)`. Одноразові токени підтвердження та скидання пароля мають порівнюватися за хешем: вихідне значення дозволено показати або надіслати користувачу лише в момент створення.

Секрет API-ключа створюється криптографічно стійким генератором і повертається лише в момент створення; інтерфейси списку та відкликання використовують тільки метадані. Для нового оточення застосовуйте відстежувані міграції командою `npx prisma migrate deploy`. У разі зміни `prisma/schema.prisma` створюйте окрему міграцію в локальній розробці, перевіряйте її на даних, близьких до production, і лише потім застосовуйте до спільних оточень.
