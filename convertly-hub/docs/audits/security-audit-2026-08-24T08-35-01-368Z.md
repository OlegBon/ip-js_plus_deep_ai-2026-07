# Аудит безопасности Convertly Hub

- **UTC-метка:** 2026-08-24T08:35:01.368Z
- **Область:** хранение секретов, конфигурация Docker, Prisma и API-маршруты.

## 1. Аудит зависимостей

`npm audit --omit=dev` обнаружил 3 уязвимости высокого уровня в транзитивной зависимости `deepmerge-ts`, поступающей через Prisma CLI. Автоматическое исправление предлагает несовместимое по версии понижение Prisma, поэтому оно не применялось. Перед обновлением следует дождаться совместимой версии Prisma с исправленной зависимостью либо отдельно спланировать миграцию.

## 2. Поиск секретов

**Исправлено.** Учётные данные PostgreSQL и MinIO были заданы в `docker-compose.yml`. Compose теперь получает их только из корневого `.env` через переменные `POSTGRES_*`, `MINIO_ACCESS_KEY` и `MINIO_SECRET_KEY`.

Проверка исходников и конфигураций не выявила других секретов вне `.env`. Файл `.env` исключён из Git правилами `.gitignore`.

## 3. Prisma Schema

`prisma/schema.prisma` использует `DATABASE_URL` из окружения. Поле пароля пользователя обязательное, строкового типа и не имеет значения по умолчанию. В схеме предусмотрено хранение API-ключей и одноразовых токенов в виде хешей.

## 4. API-маршруты

Единственный текущий маршрут `app/api/health/route.ts` создаёт подключение из `DATABASE_URL`; строка подключения не захардкожена. Входящие данные маршрут не принимает. Для будущих API-маршрутов остаются обязательными проверка авторизации и валидация входных данных.

## Рекомендации

- Перед staging/production заменить локальные учётные данные и `NEXTAUTH_SECRET` на уникальные значения из защищённого хранилища секретов.
- Не добавлять приватные переменные с префиксом `NEXT_PUBLIC_`.
- При следующем обновлении Prisma повторно выполнить `npm audit`.
