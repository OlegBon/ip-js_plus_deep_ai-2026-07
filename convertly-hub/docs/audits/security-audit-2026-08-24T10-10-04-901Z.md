# Аудит безпеки Convertly Hub

- **UTC-мітка:** 2026-08-24T10:10:04.901Z
- **Область:** `POST /api/v1/convert`, API-ключі, Prisma та API-маршрути.

## 1. Аудит залежностей

`npm audit --omit=dev` повідомляє про 3 high-вразливості у транзитивній залежності Prisma (`deepmerge-ts`). Доступний автоматичний фікс знижує Prisma до несумісної версії, тому не застосовувався.

## 2. Пошук секретів

Пошук поширених патернів AWS, GitHub і Slack-токенів у вихідному коді, виключаючи `.env`, не знайшов збігів. Значення ключів не логуються й не повертаються API.

## 3. Prisma та API-ключі

Маршрут шукає ключ лише за SHA-256-хешем, приймає тільки невідкликаний ключ активного користувача й оновлює `lastUsedAt` разом зі створенням `ConversionLog` в одній інтерактивній транзакції. Вихідний API-ключ у БД не зберігається.

## 4. Приймання файлів

`POST /api/v1/convert` потребує Bearer-аутентифікацію та `multipart/form-data`, допускає лише узгоджений набір MIME-типів і форматів призначення, обмежує файл 10 МБ і не зберігає двійковий контент до етапу Core. Помилки повертають безпечні узагальнені повідомлення.

## Рекомендації

- Реалізувати генерацію та відкликання API-ключів у наступній задачі; вихідний ключ показувати лише під час створення.
- Додати rate limiting до production.
- Повторити `npm audit` за сумісного оновлення Prisma.
