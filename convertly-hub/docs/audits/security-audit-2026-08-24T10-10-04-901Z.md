# Аудит безопасности Convertly Hub

- **UTC-метка:** 2026-08-24T10:10:04.901Z
- **Область:** `POST /api/v1/convert`, API-ключи, Prisma и API-маршруты.

## 1. Аудит зависимостей

`npm audit --omit=dev` сообщает о 3 high-уязвимостях в транзитивной зависимости Prisma (`deepmerge-ts`). Доступный автоматический фикс понижает Prisma до несовместимой версии, поэтому не применялся.

## 2. Поиск секретов

Поиск распространённых паттернов AWS, GitHub и Slack-токенов в исходном коде, исключая `.env`, не нашёл совпадений. Значения ключей не логируются и не возвращаются API.

## 3. Prisma и API-ключи

Маршрут ищет ключ только по SHA-256-хешу, принимает лишь неотозванный ключ активного пользователя и обновляет `lastUsedAt` вместе с созданием `ConversionLog` в одной интерактивной транзакции. Исходный API-ключ в БД не хранится.

## 4. Приём файлов

`POST /api/v1/convert` требует Bearer-аутентификацию и `multipart/form-data`, допускает только согласованный набор MIME-типов и форматов назначения, ограничивает файл 10 МБ и не сохраняет двоичный контент до этапа Core. Ошибки возвращают безопасные обобщённые сообщения.

## Рекомендации

- Реализовать генерацию и отзыв API-ключей в следующей задаче; исходный ключ показывать только при создании.
- Добавить rate limiting до production.
- Повторить `npm audit` при совместимом обновлении Prisma.
