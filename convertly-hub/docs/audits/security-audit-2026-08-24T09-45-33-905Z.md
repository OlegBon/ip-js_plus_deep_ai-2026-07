# Аудит безопасности Convertly Hub

- **UTC-метка:** 2026-08-24T09:45:33.905Z
- **Область:** RBAC, Telegram linking, Prisma и API-маршруты.

## 1. Аудит зависимостей

`npm audit --omit=dev` сообщает о 3 high-уязвимостях в транзитивной зависимости Prisma. Автоматический фикс требует несовместимого изменения Prisma и не применялся.

## 2. Поиск секретов

Новые Telegram-секреты хранятся только в `.env`; webhook не логирует и не возвращает токен. В БД сохраняется только SHA-256-хеш одноразового Telegram-токена.

## 3. Prisma Schema

Миграция добавляет срок Telegram-токена и audit-модель изменения ролей. Миграция подготовлена, но не применена к локальной БД в рамках этой задачи.

## 4. API-маршруты

Telegram link API требует сессию. Webhook проверяет секретный заголовок constant-time сравнением, принимает только ожидаемый формат команды и отвечает одинаковым успешным статусом для неиспользуемых обновлений. `/management` защищён на сервере и не опирается на скрытие ссылки в UI.

## Рекомендации

- Применить миграцию перед настройкой Telegram webhook.
- Настроить webhook Telegram с непустым уникальным секретом и добавить rate limiting до production.
- Повторить `npm audit` при совместимом обновлении Prisma.
