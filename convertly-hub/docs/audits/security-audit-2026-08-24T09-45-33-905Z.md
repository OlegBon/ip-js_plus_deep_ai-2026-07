# Аудит безпеки Convertly Hub

- **UTC-мітка:** 2026-08-24T09:45:33.905Z
- **Область:** RBAC, Telegram linking, Prisma та API-маршрути.

## 1. Аудит залежностей

`npm audit --omit=dev` повідомляє про 3 high-вразливості у транзитивній залежності Prisma. Автоматичний фікс потребує несумісної зміни Prisma та не застосовувався.

## 2. Пошук секретів

Нові Telegram-секрети зберігаються лише у `.env`; webhook не логує та не повертає токен. У БД зберігається лише SHA-256-хеш одноразового Telegram-токена.

## 3. Prisma Schema

Міграція додає строк Telegram-токена та audit-модель зміни ролей. Міграцію підготовлено, але не застосовано до локальної БД у межах цієї задачі.

## 4. API-маршрути

Telegram link API потребує сесію. Webhook перевіряє секретний заголовок constant-time порівнянням, приймає лише очікуваний формат команди та відповідає однаковим успішним статусом для невикористаних оновлень. `/management` захищено на сервері та не спирається на приховування посилання в UI.

## Рекомендації

- Застосувати міграцію перед налаштуванням Telegram webhook.
- Налаштувати webhook Telegram з непорожнім унікальним секретом і додати rate limiting до production.
- Повторити `npm audit` за сумісного оновлення Prisma.
