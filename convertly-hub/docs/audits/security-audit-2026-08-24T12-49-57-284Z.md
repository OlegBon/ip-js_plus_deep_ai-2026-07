# Аудит безпеки Convertly Hub

- **UTC-мітка:** 2026-08-24T12:49:57.284Z
- **Область:** rate limiting, валідація завантаження та API-конвертація.

## 1. Аудит залежностей

`npm audit --omit=dev` повідомляє про 3 вразливості рівня **high** у транзитивному ланцюжку `prisma` → `@prisma/config` → `deepmerge-ts` (GHSA-ggr8-5vv4-36mx). Запропонований `npm audit fix --force` є breaking-зміною Prisma та у межах цієї задачі не застосовувався.

## 2. Пошук секретів

Пошук за відстежуваним кодом не виявив production API-ключів, приватних ключів або AWS access key. Значення `.env` не читалися й не включалися до звіту.

## 3. Аналіз Prisma Schema

Схема не змінювалася. `User.password` залишається обов'язковим рядком без значення за замовчуванням для bcrypt-хешу. `ApiKey.keyHash` залишається унікальним хешем, а не вихідним секретом.

## 4. Аналіз API-маршрутів

- `POST /api/v1/convert` спочатку аутентифікує API-ключ, потім застосовує ліміт 30 запитів на хвилину на ключ. Перевищення повертає `429` і `Retry-After` до оброблення тіла файлу.
- Розмір, MIME і цільовий формат перевіряються до читання файлу в `Buffer`; Core окремо перевіряє сигнатуру. Некоректні дані повертають безпечні `413`, `415` або `422` без внутрішніх деталей воркера.
- Лімітер не використовує БД і мережеві виклики. Він in-memory та коректний для одного процесу; для кількох інстансів потрібен спільний Redis-сумісний backend, інакше ліміт буде окремим для кожного екземпляра.
- API-аудит підтвердив доступність застосунку, PostgreSQL, Gotenberg і MinIO у локальному середовищі.
