# Аудит безопасности Convertly Hub

- **UTC-метка:** 2026-08-24T12:49:57.284Z
- **Область:** rate limiting, валидация загрузки и API-конвертация.

## 1. Аудит зависимостей

`npm audit --omit=dev` сообщает о 3 уязвимостях уровня **high** в транзитивной цепочке `prisma` → `@prisma/config` → `deepmerge-ts` (GHSA-ggr8-5vv4-36mx). Предлагаемый `npm audit fix --force` является breaking-изменением Prisma и в рамках этой задачи не применялся.

## 2. Поиск секретов

Поиск по отслеживаемому коду не выявил production API-ключей, приватных ключей или AWS access key. Значения `.env` не читались и не включались в отчёт.

## 3. Анализ Prisma Schema

Схема не менялась. `User.password` остаётся обязательной строкой без значения по умолчанию для bcrypt-хеша. `ApiKey.keyHash` остаётся уникальным хешем, а не исходным секретом.

## 4. Анализ API-маршрутов

- `POST /api/v1/convert` сначала аутентифицирует API-ключ, затем применяет лимит 30 запросов в минуту на ключ. Превышение возвращает `429` и `Retry-After` до обработки тела файла.
- Размер, MIME и целевой формат проверяются до чтения файла в `Buffer`; Core отдельно проверяет сигнатуру. Некорректные данные возвращают безопасные `413`, `415` или `422` без внутренних деталей воркера.
- Лимитер не использует БД и сетевые вызовы. Он in-memory и корректен для одного процесса; для нескольких инстансов требуется общий Redis-совместимый backend, иначе лимит будет раздельным для каждого экземпляра.
- API-аудит подтвердил доступность приложения, PostgreSQL, Gotenberg и MinIO в локальной среде.
