# Аудит безпеки Convertly Hub

- **UTC-мітка:** 2026-08-24T13:03:52.000Z
- **Область:** API адмін-панелі, RBAC, Prisma-запити та керування API-ключами.

## 1. Аудит залежностей

`npm audit --omit=dev` повідомляє про 3 вразливості рівня **high** у транзитивному ланцюжку `prisma` → `@prisma/config` → `deepmerge-ts` (GHSA-ggr8-5vv4-36mx). Автоматичний `npm audit fix --force` потребує breaking-зміни Prisma та не застосовувався.

## 2. Пошук секретів

Пошук за відстежуваним кодом не виявив production API-ключів, приватних ключів або AWS access key. Значення `.env` не читалися й не включалися до звіту.

## 3. Аналіз Prisma Schema

Схема не змінювалася. `User.password` залишається обов'язковим рядком без значення за замовчуванням для bcrypt-хешу; `ApiKey.keyHash` залишається унікальним хешем. Індекси `User.status` і `ApiKey(userId, revokedAt)` відповідають наявним сценаріям фільтрації та керування ключами. Пошук підрядком `contains` за іменем/email не має спеціалізованого індексу: для великої таблиці після перевірки `EXPLAIN` знадобиться окремий `pg_trgm` індекс.

## 4. Аналіз API-маршрутів

- Усі `/api/admin/*` маршрути потребують сесію та перед операцією звіряють актуальні `role=ADMIN` і `status=ACTIVE` через обмежений Prisma `select`; застарілий JWT сам собою прав не надає.
- Видача користувачів використовує cursor-pagination, ліміт 1–50 і не повертає пароль, токени, хеші або API-секрети.
- Зміна статусу приймає лише `ACTIVE`/`SUSPENDED`, а власний статус адміністратора заборонений. Відкликання API-ключа виконується атомарним `updateMany` лише для ще активного ключа; історія конвертацій зберігається.
- Raw SQL, конкатенація користувацького вводу та мережеві виклики всередині транзакцій відсутні. API-аудит підтвердив доступність застосунку, PostgreSQL, Gotenberg і MinIO у локальному середовищі.
