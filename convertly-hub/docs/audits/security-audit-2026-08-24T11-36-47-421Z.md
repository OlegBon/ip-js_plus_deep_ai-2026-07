# Аудит безпеки Convertly Hub

- **UTC-мітка:** 2026-08-24T11:36:47.421Z
- **Область:** Core-конвертація, `POST /api/v1/convert`, Prisma і Gotenberg.

## 1. Аудит залежностей

`npm audit --omit=dev` повідомляє про 3 high-вразливості у транзитивній залежності Prisma (`deepmerge-ts`). Доступний автоматичний фікс потребує несумісної зміни Prisma, тому не застосовувався.

## 2. Пошук секретів

Пошук поширених патернів AWS, GitHub і OpenAI-токенів у вихідному коді, виключаючи `.env`, не знайшов збігів. Значення API-ключів, рядків підключення та відповідей Gotenberg не логуються й не повертаються клієнту.

## 3. Prisma Schema

Схема не змінювалася: `ConversionLog` уже містить обов'язкові поля вихідного файлу та статус, а також nullable-метадані результату. Фонова задача виконує короткі параметризовані оновлення статусу до й після зовнішнього HTTP-виклику; мережевий виклик не виконується всередині транзакції.

## 4. API та Core

Маршрут перевіряє Bearer API-ключ, `multipart/form-data`, розмір і дозволені MIME-типи. Core додатково звіряє сигнатури JPG, PNG і ZIP-контейнера DOCX; Gotenberg викликається з таймаутом 30 секунд, а його відповідь приймається лише за PDF-сигнатури. Помилки воркера зберігаються та повертаються лише безпечним узагальненим текстом.

## Рекомендації

- Додати rate limiting і антивірусне сканування до production.
- Для DOCX посилити перевірку ZIP-контейнера перевіркою обов'язкових внутрішніх частин Office Open XML.
- Повторити `npm audit` за сумісного оновлення Prisma.
