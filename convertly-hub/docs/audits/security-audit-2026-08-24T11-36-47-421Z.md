# Аудит безопасности Convertly Hub

- **UTC-метка:** 2026-08-24T11:36:47.421Z
- **Область:** Core-конвертация, `POST /api/v1/convert`, Prisma и Gotenberg.

## 1. Аудит зависимостей

`npm audit --omit=dev` сообщает о 3 high-уязвимостях в транзитивной зависимости Prisma (`deepmerge-ts`). Доступный автоматический фикс требует несовместимого изменения Prisma, поэтому не применялся.

## 2. Поиск секретов

Поиск распространённых паттернов AWS, GitHub и OpenAI-токенов в исходном коде, исключая `.env`, не нашёл совпадений. Значения API-ключей, строк подключения и ответов Gotenberg не логируются и не возвращаются клиенту.

## 3. Prisma Schema

Схема не менялась: `ConversionLog` уже содержит обязательные поля исходного файла и статус, а также nullable-метаданные результата. Фоновая задача делает короткие параметризованные обновления статуса до и после внешнего HTTP-вызова; сетевой вызов не выполняется внутри транзакции.

## 4. API и Core

Маршрут проверяет Bearer API-ключ, `multipart/form-data`, размер и разрешённые MIME-типы. Core дополнительно сверяет сигнатуры JPG, PNG и ZIP-контейнера DOCX; Gotenberg вызывается с таймаутом 30 секунд, а его ответ принимается только при PDF-сигнатуре. Ошибки воркера сохраняются и возвращаются только безопасным обобщённым текстом.

## Рекомендации

- Добавить rate limiting и антивирусное сканирование до production.
- Для DOCX усилить проверку ZIP-контейнера проверкой обязательных внутренних частей Office Open XML.
- Повторить `npm audit` при совместимом обновлении Prisma.
