# Аудит безопасности Convertly Hub

- **UTC-метка:** 2026-08-24T09:24:26.724Z
- **Область:** регистрация, вход по паролю, NextAuth.js, Prisma и API-маршруты.

## 1. Аудит зависимостей

`npm audit --omit=dev` обнаружил 3 уязвимости высокого уровня в транзитивной зависимости `deepmerge-ts`, поступающей через Prisma CLI. Автоматическое исправление предлагает несовместимое изменение версии Prisma, поэтому оно не применялось.

## 2. Поиск секретов

В новом коде регистрации и входа нет захардкоженных секретов. Пароли не логируются и не возвращаются API; секрет NextAuth остаётся приватной переменной окружения.

## 3. Prisma Schema

Схема не менялась. Поле `User.password` используется только для bcrypt-хеша. Доступ к данным осуществляется Prisma Client с ограниченным `select`: хеш не передаётся после создания пользователя и не включается в сессию.

## 4. API-маршруты

`POST /api/auth/register` принимает JSON, отвергает некорректное тело и создаёт пользователя только после серверной валидации. Credentials Provider нормализует email, проверяет bcrypt-хеш и отклоняет заблокированные аккаунты с единым результатом отказа. Успешный вход обновляет `lastLoginAt`; JWT передаёт клиенту только идентификатор и роль пользователя.

## Рекомендации

- До публикации добавить rate limiting на регистрацию и вход.
- Использовать уникальный production `NEXTAUTH_SECRET` из защищённого хранилища.
- При обновлении Prisma повторить `npm audit` и выбрать совместимое исправление зависимости.
