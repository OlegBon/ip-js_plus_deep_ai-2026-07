# Аудит безпеки Convertly Hub

- **UTC-мітка:** 2026-08-24T09:24:26.724Z
- **Область:** реєстрація, вхід за паролем, NextAuth.js, Prisma та API-маршрути.

## 1. Аудит залежностей

`npm audit --omit=dev` виявив 3 вразливості високого рівня у транзитивній залежності `deepmerge-ts`, що надходить через Prisma CLI. Автоматичне виправлення пропонує несумісну зміну версії Prisma, тому його не застосовували.

## 2. Пошук секретів

У новому коді реєстрації та входу немає захардкожених секретів. Паролі не логуються й не повертаються API; секрет NextAuth залишається приватною змінною оточення.

## 3. Prisma Schema

Схема не змінювалася. Поле `User.password` використовується лише для bcrypt-хешу. Доступ до даних здійснюється Prisma Client з обмеженим `select`: хеш не передається після створення користувача та не включається до сесії.

## 4. API-маршрути

`POST /api/auth/register` приймає JSON, відхиляє некоректне тіло та створює користувача лише після серверної валідації. Credentials Provider нормалізує email, перевіряє bcrypt-хеш і відхиляє заблоковані акаунти з єдиним результатом відмови. Успішний вхід оновлює `lastLoginAt`; JWT передає клієнту лише ідентифікатор і роль користувача.

## Рекомендації

- До публікації додати rate limiting на реєстрацію та вхід.
- Використовувати унікальний production `NEXTAUTH_SECRET` із захищеного сховища.
- За оновлення Prisma повторити `npm audit` і обрати сумісне виправлення залежності.
