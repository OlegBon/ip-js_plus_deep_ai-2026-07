# Звіт аудиту безпеки — 2026-08-24T12:01:47.252Z

## Перевірки

- Проведено аудит API: застосунок, PostgreSQL, Gotenberg і MinIO доступні у локальному оточенні.
- Для `POST /api/v1/convert` перевірено два режими приватності: за `storeConversions=true` файл зберігається лише у приватному user-scoped S3-ключі; за `false` S3 не викликається, а відповідь має `Cache-Control: no-store`.
- `GET /api/v1/conversions/:conversionId/download` потребує Bearer API-ключ, обмежує запит `userId` власника та повертає `404` для чужого або відсутнього результату без розкриття його існування.
- Публічні та presigned S3 URL не формуються. Зовнішні виклики S3 і Core виконуються поза Prisma-транзакціями.
- Пошук відстежуваного коду не виявив захардкожених production-секретів. Збіги `DATABASE_URL` розташовані лише у навчальних прикладах `.agents/skills` і не є конфігурацією застосунку.

## Залежності

`npm audit --omit=dev` виявив 3 вразливості рівня **high** у транзитивному ланцюжку `prisma` → `@prisma/config` → `deepmerge-ts` (GHSA-ggr8-5vv4-36mx). Доступне автоматичне виправлення потребує `npm audit fix --force` і знижує Prisma до 6.12.0, тобто є breaking-зміною. Його не застосовували у межах цієї задачі.
