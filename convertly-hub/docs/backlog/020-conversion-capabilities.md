# 020 — Можливості та діагностика конвертацій

## PDF → DOCX

Функція навмисно не реалізована. Потрібні спеціалізований best-effort engine,
еталонні документи та UX-попередження про можливу втрату форматування.

## Діагностика failed conversion

Операційний інтерфейс, безпечна деталь failed запису та видалення збережених
результатів винесені в окрему задачу
[060-admin-conversion-history.md](./060-admin-conversion-history.md). Здесь
лишається лише продуктова частина: які нові формати та критерії якості
потрібні для конвертера.

## Перевірки

Додати реальні тестові файли різного розміру, окремий test для Gotenberg
timeout і контроль того, що failed task не витрачає місячну квоту.
