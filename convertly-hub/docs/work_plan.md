## Backend

1.  **Аутентификация пользователей:** Настроить `NextAuth.js` для управления сессиями через HttpOnly cookies.
2.  **Логика регистрации/входа:** Реализовать хэширование паролей (`bcrypt`) и проверку учетных данных.
3.  **API для конвертации (`POST /api/v1/convert`):**
    - Создать основной маршрут для приёма `multipart/form-data` запросов.
    - Реализовать аутентификацию по Bearer токену (API-ключ).
4.  **Ядро конвертации (Core):**
    - Интегрировать библиотеку `sharp` для быстрой обработки изображений (JPG ↔ PNG).
    - Реализовать логику делегирования конвертации документов (DOCX → PDF) воркеру `Gotenberg`.
5.  **Управление приватностью:** Написать логику, которая в зависимости от настроек пользователя либо сохраняет файл в S3, либо отдает его потоком.
6.  **Генерация API-ключей:** Разработать механизм создания, хэширования и отзыва API-ключей.
7.  **Безопасность и валидация:**
    - Реализовать ограничение частоты запросов (Rate Limiting) для API.
    - Добавить серверную валидацию размера (`Payload Too Large`) и типа (`MIME-type`) файлов.
    - Обеспечить корректную обработку ошибок от воркеров (например, `422 Unprocessable Entity`).
8.  **Логика для Админ-панели:** Создать API-эндпоинты для поиска, блокировки пользователей и отзыва ключей.

## База данных и Инфраструктура

1.  **Локальное окружение:** Настроить и запустить сервисы `postgres`, `minio` и `gotenberg` через `docker-compose.yml`.
2.  **Схема данных:** Финализировать схему в `prisma/schema.prisma`, добавив модели `User`, `ApiKey`, `ConversionLog` и другие необходимые сущности.
3.  **Миграции:** Создать и применить миграции базы данных с помощью `prisma migrate dev`.
4.  **Интеграция с S3:** Написать сервисные функции для загрузки, скачивания и удаления файлов из S3-совместимого хранилища (MinIO).
