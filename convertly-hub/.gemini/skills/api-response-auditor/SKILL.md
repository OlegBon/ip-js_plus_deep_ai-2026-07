# Цель навыка

Проведение аудита API с использованием заранее подготовленного скрипта проекта для обеспечения надежности и детерминированности проверок.

# Триггеры активации

Активируй, если пользователь просит: "сделай аудит эндпоинтов", "проверь ответы API", "сформируй отчет по API".

# Инструкции по выполнению

Тебе ЗАПРЕЩЕНО писать собственные скрипты или использовать fetch напрямую для этой задачи. Действуй строго по шагам:

## Шаг 1: Запуск аудита

Используя инструмент выполнения команд в терминале, запусти скрипт аудита: `npm run audit:api`.

## Шаг 2: Ожидание

Дождись завершения работы скрипта в терминале (ты должен увидеть сообщение об успешном сохранении).

## Шаг 3: Чтение отчета

Используя инструмент чтения файлов, открой сгенерированный файл `docs/audits/api-audit-latest.md`.

# Формат вывода

1. Сделай краткую выжимку из прочитанного отчета `api-audit-latest.md` (статус эндпоинтов и 2-3 главные проблемы, если они есть).
2. Заверши свой ответ строго фразой: _"Аудит API завершен. Отчеты сформированы. Жду дальнейших указаний."_
