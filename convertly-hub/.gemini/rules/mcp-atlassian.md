# Правила использования MCP: Atlassian

## Сценарии использования

Инструменты `Atlassian` (Teamwork Graph) используются для получения информации о связях между сущностями Atlassian (Jira, Confluence) и другими инструментами.

## Типичные задачи

- **Поиск связанных задач:** Когда нужно понять, какие задачи Jira связаны с определенным проектом, эпиком или спринтом. (`getTeamworkGraphContext`)
- **Поиск владельцев:** Найти ответственного за компонент, проект или задачу. (`getTeamworkGraphContext` с `targetObjectTypes=["AtlassianUser"]`)
- **Получение деталей:** После нахождения нужных объектов (задач, страниц) через `getTeamworkGraphContext`, используй `getTeamworkGraphObject` для получения их полного содержимого (описание, статус, комментарии).

## Алгоритм исследования

1.  **Определи точку входа:** Начни с известной тебе сущности (например, тикет Jira `PROJ-123` или страница Confluence).
2.  **Запроси контекст:** Используй `getTeamworkGraphContext`, указав `objectType` и `objectIdentifier`. Ты можешь фильтровать связи по `relationshipTypes` или `targetObjectTypes` для более точного поиска.
3.  **Извлеки ARIs:** Из ответа `getTeamworkGraphContext` получи ARIs (Atlassian Resource Identifiers) интересующих тебя связанных объектов.
4.  **Получи детали:** Передай эти ARIs в `getTeamworkGraphObject`, чтобы загрузить полную информацию о них.
5.  **Проанализируй и ответь:** На основе полученных данных дай пользователю ответ на его вопрос (например, "Задачу `PROJ-123` блокирует тикет `PROJ-456`, который находится в статусе 'In Review'").
