# Правила использования MCP: Context7

## Сценарии использования

Ты **обязан** использовать `Context7` в следующих случаях:

1.  **Запрос документации:** Когда пользователь спрашивает о любой библиотеке, фреймворке, API, SDK или CLI (например, `Next.js`, `React`, `Tailwind CSS`, `Prisma`, `Express`).
2.  **Генерация кода:** Когда нужно сгенерировать код, использующий определённую библиотеку (`"Как сделать X с помощью Y?"`).
3.  **Установка и настройка:** Когда пользователь просит инструкции по установке, настройке или миграции версий.
4.  **Решение проблем:** При возникновении ошибок, специфичных для какой-либо библиотеки (например, ошибки конфигурации, неправильное использование API).

## Алгоритм действий

1.  **Определи библиотеку:** Из запроса пользователя извлеки точное название библиотеки.
2.  **Используй `resolve_library_id`:** Найди правильный ID библиотеки для Context7.
3.  **Сформулируй точный запрос:** С помощью `query_docs` задай конкретный вопрос, касающийся проблемы.
    - **Хороший запрос:** `"How to fetch data in Server Components in Next.js"`
    - **Плохой запрос:** `"Next.js data fetching"`
4.  **Анализ и ответ:** Проанализируй полученную документацию и предоставь пользователю точный ответ или готовый фрагмент кода, адаптированный под наш проект.
