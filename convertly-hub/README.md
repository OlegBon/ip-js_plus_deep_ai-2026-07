# 🛡️ Convertly Hub

> Современный SaaS-сервис для конвертации документов и файлов с предоставлением публичного API. Разработан в рамках задания на курсе "Javascript + deep AI" (Ivan Petrychenko, 2026-07) для демонстрации навыков Full Stack разработки и системной архитектуры.

---

## 🛠️ Технологический стек

- **Фронтенд / Оркестратор:** Next.js (App Router), React, TypeScript, Tailwind CSS
- **Бэкенд и API (целевой стек):** Next.js API Routes, NextAuth.js, Prisma ORM (v7)
- **База данных:** PostgreSQL (в Docker)
- **Файловое хранилище:** MinIO (S3-совместимое объектное хранилище)
- **Движок конвертации:** Gotenberg (Chromium + LibreOffice в изолированном контейнере)
- **Контейнеризация:** Docker Compose

---

## 📐 Архитектура проекта

Проект построен по принципу микросервисной изоляции тяжелых задач:

1. **Next.js** управляет интерфейсом и принимает запросы от пользователей.
2. **Prisma ORM** с драйвером `@prisma/adapter-pg` уже используется проверкой здоровья; CRUD-слой приложения ещё не реализован.
3. **MinIO** используется локальным серверным S3-сервисом для загрузки, скачивания и удаления объектов; пользовательские потоки конвертации подключат его отдельной задачей.
4. **Gotenberg** запускается как воркер и проверяется health-маршрутом; поток конвертации ещё не реализован.

## 🚀 Быстрый старт (Локальная разработка)

Подробное руководство по развертыванию инфраструктуры находится в файле [START.md](./START.md).

1. Клонируйте репозиторий и установите зависимости:

```bash
git clone <url-репозитория>
cd convertly-hub
npm install
```

2. Поднимите инфраструктуру (PostgreSQL, MinIO, Gotenberg) через Docker:

```bash
docker compose up -d
```

3. Настройте файл `.env` по переменным, указанным в [START.md](./START.md). Файл `.env.example` пока отсутствует.
4. Примените миграции базы данных и сгенерируйте Prisma Client:

```bash
npx prisma migrate deploy
npx prisma generate
```

5. Запустите проект в режиме разработки:

```bash
npm run dev
```

## ⚠️ Текущий статус

Готов frontend-прототип с компонентными тестами и критическими E2E-сценариями, Prisma-схема с применяемыми миграциями и `GET /api/health`. Реальные аутентификация, конвертация, работа с S3, API-ключами, платежами и серверная админ-панель остаются задачами из [плана работ](./docs/work_plan.md). Страницы `/docs`, Dashboard и Management показывают целевой UX и не являются документацией работающего публичного API.
