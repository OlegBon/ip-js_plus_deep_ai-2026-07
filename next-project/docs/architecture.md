# Архитектура Проекта "next-project"

Этот документ описывает текущую архитектуру веб-приложения, построенного на Next.js.

## 1. Технологический стек

- **Фреймворк:** [Next.js](https://nextjs.org/) (App Router)
- **Библиотека UI:** [React](https://react.dev/)
- **Язык:** [TypeScript](https://www.typescriptlang.org/)
- **Стилизация:** [Tailwind CSS](https://tailwindcss.com/)
- **Линтинг:** [ESLint](https://eslint.org/)

## 2. Структура директорий

### 2.1. Визуальная структура

```
/next-project
├── app/                    # Исходные файлы приложения (App Router)
│   └── lib/                # Вспомогательная бизнес-логика
├── docs/                   # Проектная документация
├── node_modules/           # Зависимости проекта
├── public/                 # Статические ассеты (изображения, шрифты)
└── .gemini/                # Правила для AI-агента
    └── rules/              # Детализированные файлы правил
├── .gitignore              # Файл для исключения файлов из Git
├── next.config.ts          # Конфигурация Next.js
├── package.json            # Зависимости и скрипты
├── postcss.config.mjs      # Конфигурация PostCSS
├── tailwind.config.js      # Конфигурация Tailwind CSS
├── tsconfig.json           # Конфигурация TypeScript
└── README.md               # Документация по проекту
```

Проект использует стандартную для Next.js структуру с App Router.

- `next-project/`
  - `app/`: Основная директория для страниц и компонентов приложения.
    - `layout.tsx`: Корневой макет приложения, оборачивающий все страницы.
    - `page.tsx`: Главная страница (роут `/`).
    - `globals.css`: Глобальные стили, включая базовые настройки Tailwind CSS.
    - `lib/`: Директория для вспомогательного кода и бизнес-логики.
      - `api.js`: Функции для взаимодействия с внешними API (например, через `fetch`).
      - `calculator.js`, `analyzer.js`: Модули, содержащие основную бизнес-логику приложения (например, финансовые расчеты).
      - `adapters.js`: Адаптеры для преобразования данных, полученных от внешних сервисов, в формат, удобный для использования в приложении.
      - `config.js`: Конфигурационные константы и настройки.
  - `public/`: Директория для статических файлов (изображения, иконки, шрифты).
  - `docs/`: Проектная документация.
    - `architecture.md`: Этот файл.
    - `progress.md`: Журнал выполненных задач.
    - `db-schema.md`: Описание схемы базы данных.
  - `.gemini/`: Правила и настройки для AI-агента.
  - `node_modules/`: Зависимости проекта.
  - `*.json`, `*.js`, `*.mjs`: Файлы конфигурации проекта (Next.js, TypeScript, PostCSS, ESLint).

## 3. Поток данных и рендеринг

1.  **Рендеринг:** Приложение использует преимущественно **серверные компоненты React (RSC)** для уменьшения нагрузки на клиент и безопасного доступа к данным. Клиентские компоненты (`"use client"`) используются только там, где необходима интерактивность (хуки, обработчики событий).
2.  **Получение данных:** Данные из внешних API извлекаются напрямую в серверных компонентах с использованием `async/await` и `fetch`.
3.  **Состояния UI:** Для управления состояниями загрузки и ошибок используются встроенные в Next.js файлы `loading.tsx` и `error.tsx`.

## 4. Стилизация

Стилизация полностью построена на утилитарных классах **Tailwind CSS**. Глобальные стили сведены к минимуму. Переиспользуемые наборы стилей инкапсулируются внутри UI-компонентов.
