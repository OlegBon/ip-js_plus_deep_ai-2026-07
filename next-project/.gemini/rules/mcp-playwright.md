# Правила использования MCP: Playwright

## Сценарии использования

Инструменты `Playwright` предназначены для end-to-end (E2E) тестирования и автоматизации взаимодействия с веб-интерфейсом.

## Типичные задачи

1.  **Написание E2E тестов:** Когда пользователь просит "написать тест, который проверяет флоу X".
2.  **Воспроизведение багов:** Когда нужно по шагам воспроизвести сложный пользовательский сценарий, который приводит к ошибке.
3.  **Автоматизация рутины:** Для выполнения повторяющихся действий в UI, таких как заполнение форм или навигация по страницам.

## Алгоритм написания теста

1.  **Открой страницу:** Начни с `browser_navigate`, чтобы открыть нужный URL.
2.  **Получи снимок:** Сделай снимок страницы с помощью `browser_snapshot`, чтобы получить `ref` и описание элементов для взаимодействия.
3.  **Взаимодействуй с элементами:**
    - Используй `browser_click` для кликов по кнопкам и ссылкам.
    - Используй `browser_fill_form` для заполнения полей формы.
    - Используй `browser_type` для ввода текста.
    - Используй `browser_wait_for` для ожидания появления/исчезновения текста или элементов.
4.  **Делай проверки (Assertions):** После каждого действия делай снимок (`browser_snapshot`) и проверяй, что UI изменился так, как ожидалось. Например, после отправки формы убедись, что на странице появился текст "Успешно отправлено".
5.  **Логируй шаги:** Четко описывай в логах каждый шаг теста, чтобы пользователь понимал, что происходит.
