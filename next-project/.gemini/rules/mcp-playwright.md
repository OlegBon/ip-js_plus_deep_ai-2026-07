# Правила використання MCP: Playwright

## Сценарії використання

Інструменти `Playwright` призначені для end-to-end (E2E) тестування й автоматизації взаємодії з вебінтерфейсом.

## Типові завдання

1.  **Написання E2E-тестів:** коли користувач просить «написати тест, який перевіряє флоу X».
2.  **Відтворення багів:** коли потрібно крок за кроком відтворити складний користувацький сценарій, що призводить до помилки.
3.  **Автоматизація рутини:** для виконання повторюваних дій в UI, як-от заповнення форм або навігація сторінками.

## Алгоритм написання тесту

1.  **Відкрий сторінку:** почни з `browser_navigate`, щоб відкрити потрібний URL.
2.  **Отримай знімок:** зроби знімок сторінки за допомогою `browser_snapshot`, щоб отримати `ref` і опис елементів для взаємодії.
3.  **Взаємодій з елементами:**
    - використовуй `browser_click` для кліків кнопками та посиланнями;
    - використовуй `browser_fill_form` для заповнення полів форми;
    - використовуй `browser_type` для введення тексту;
    - використовуй `browser_wait_for` для очікування появи/зникнення тексту або елементів.
4.  **Виконуй перевірки (Assertions):** після кожної дії роби знімок (`browser_snapshot`) і перевіряй, що UI змінився як очікувалося. Наприклад, після надсилання форми переконайся, що на сторінці з'явився текст «Успішно надіслано».
5.  **Логуй кроки:** чітко описуй у логах кожен крок тесту, щоб користувач розумів, що відбувається.
