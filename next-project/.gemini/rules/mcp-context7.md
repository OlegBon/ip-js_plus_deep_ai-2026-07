# Правила використання MCP: Context7

## Сценарії використання

Ти **зобов'язаний** використовувати `Context7` у таких випадках:

1.  **Запит документації:** коли користувач запитує про будь-яку бібліотеку, фреймворк, API, SDK або CLI (наприклад, `Next.js`, `React`, `Tailwind CSS`, `Prisma`, `Express`).
2.  **Генерація коду:** коли потрібно згенерувати код, що використовує певну бібліотеку (`"Як зробити X за допомогою Y?"`).
3.  **Встановлення та налаштування:** коли користувач просить інструкції зі встановлення, налаштування або міграції версій.
4.  **Розв'язання проблем:** у разі помилок, специфічних для певної бібліотеки (наприклад, помилок конфігурації або неправильного використання API).

## Алгоритм дій

1.  **Визнач бібліотеку:** з запиту користувача витягни точну назву бібліотеки.
2.  **Використай `resolve_library_id`:** знайди правильний ID бібліотеки для Context7.
3.  **Сформулюй точний запит:** за допомогою `query_docs` постав конкретне запитання щодо проблеми.
    - **Добрий запит:** `"How to fetch data in Server Components in Next.js"`
    - **Поганий запит:** `"Next.js data fetching"`
4.  **Аналіз і відповідь:** проаналізуй отриману документацію та надай користувачу точну відповідь або готовий фрагмент коду, адаптований до нашого проєкту.
