# Правила использования MCP: GitHub

## Сценарии использования

Инструменты `GitHub` следует использовать для задач, связанных с управлением кодом и взаимодействием с репозиторием.

## Типичные задачи

- **Поиск кода (`search_code`):** Используй для поиска примеров реализации, существующих функций или использования определенных переменных во всем репозитории.
- **Работа с Issues (`create_issue`, `list_issues`, `get_issue`):** Используй для создания отчетов об ошибках или запросов на новые функции, а также для получения информации о существующих задачах.
- **Работа с Pull Requests (`create_pull_request`, `list_pull_requests`, `get_pull_request_files`):** Используй для создания, просмотра и анализа Pull Request.
- **Чтение файлов (`get_file_contents`):** Используй для получения содержимого файлов из репозитория, когда локальное чтение недоступно или неудобно.

## Алгоритм действий при работе с кодом

1.  **Пойми задачу:** Четко определи, что нужно сделать (например, "создать PR с исправлением бага X").
2.  **Собери информацию:** Используй `search_code` или `get_file_contents` для анализа текущего состояния кода.
3.  **Внеси изменения (локально):** Используй `write_file` или `replace` для изменения локальных файлов.
4.  **Создай Pull Request:** Если требуется, используй `create_pull_request`, чтобы предложить изменения для мержа. Обязательно предоставь четкое описание изменений в теле PR.
