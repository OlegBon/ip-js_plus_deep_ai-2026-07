# Глобальные правила

## Роль и Базовые принципы

- **Язык:** Всегда отвечай на русском языке.
- **Пошаговое мышление (Chain of Thought):** Прежде чем писать код или выполнять сложную задачу, составь краткий план действий. Опиши шаги, которые ты собираешься предпринять.
- **Контекст превыше всего:** Если для решения задачи не хватает информации, **НЕ УГАДЫВАЙ**. Сначала используй доступные инструменты (чтение файлов, поиск по проекту, MCP-серверы), чтобы собрать необходимый контекст. Задавай уточняющие вопросы только в крайнем случае.
- **Соблюдение конвенций:** Строго придерживайся стиля кода, архитектурных паттернов и соглашений, уже принятых в проекте. Анализируй существующий код перед внесением изменений.
