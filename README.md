# Домашні завдання курсу JavaScript + Deep AI

Репозиторій із домашніми завданнями та навчальними проєктами курсу Івана Петриченка (потік 2026-07). Роботи показують шлях від базового JavaScript та інтеграції AI-сервісів до проєктування й реалізації SaaS-застосунку.

## Зміст

| Каталог | Короткий опис |
| --- | --- |
| [`hw-2026-07-17`](./hw-2026-07-17) | Базовий JavaScript: розрахунок денної виручки з двох джерел даних. Є власне рішення та варіант, підготовлений за допомогою AI; розглянуто перевірку вхідних даних і граничні випадки. |
| [`vite-project`](./vite-project) | Невеликий застосунок на Vite і Tailwind CSS. На прикладі калькулятора виручки опрацьовано конфігурацію через змінні середовища, роботу з API та патерн «Адаптер» для приведення різних джерел даних до єдиного формату. |
| [`next-project`](./next-project) | Перенесення [`vite-project`](./vite-project) на Next.js: інтерфейс для розрахунку й аналізу транзакцій, сторінка джерел даних, прикладні модулі та API-аудит. Використано React, TypeScript, Tailwind CSS і ESLint. |
| [`hw-2026-08-03`](./hw-2026-08-03) | Проєктування трьох вебпродуктів: персонального дашборда з AI-асистентом, інтернет-магазину з адмінпанеллю та SaaS-конвертера файлів із публічним API. Документи містять стек, користувацькі сценарії, безпеку й архітектурні рішення. |
| [`hw-2026-08-05`](./hw-2026-08-05) | Технічна специфікація й архітектура Convertly Hub — SaaS-платформи для конвертації JPG/PNG та DOCX/PDF. Описано Next.js, PostgreSQL/Prisma, S3-сумісне сховище, ізольовані воркери, авторизацію та rate limiting. |
| [`hw-2026-08-06`](./hw-2026-08-06) | Дизайн-етап Convertly Hub: фінальна дизайн-система, токени, компоненти, варіанти візуального напряму й аналіз референсів Vercel та Pirsch Analytics. |
| [`convertly-hub`](./convertly-hub) | Підсумкова повнофункціональна реалізація Convertly Hub на Next.js. Містить конвертацію файлів, публічний API та API-ключі, акаунти й ролі, особистий кабінет, підписки та квоти, S3-сховище, Prisma/PostgreSQL, Docker-конфігурації й автоматичні тести. |

## Технології

JavaScript, TypeScript, React, Next.js, Vite, Tailwind CSS, PostgreSQL, Prisma, NextAuth/Auth.js, S3-сумісне сховище, Docker, Jest и Playwright.

## Запуск застосунків

У кожного застосунку власні залежності та інструкції. Перейди до потрібного каталогу й установи їх:

```bash
cd vite-project # або next-project / convertly-hub
npm install
npm run dev
```

Для `convertly-hub` перед запуском також знадобляться змінні середовища та інфраструктурні сервіси; див. його [README](./convertly-hub/README.md) та [інструкцію локального запуску](./convertly-hub/docs/local-start.md).
