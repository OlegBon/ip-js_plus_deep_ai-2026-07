# Домашние задания курса JavaScript + Deep AI

Репозиторий с домашними заданиями и учебными проектами курса Ивана Петриченко (поток 2026-07). Работы показывают путь от базового JavaScript и интеграции AI-сервисов к проектированию и реализации SaaS-приложения.

## Содержание

| Каталог | Краткое описание |
| --- | --- |
| [`hw-2026-07-17`](./hw-2026-07-17) | Базовый JavaScript: расчёт дневной выручки из двух источников данных. Есть собственное решение и вариант, подготовленный с помощью AI; рассмотрены проверка входных данных и граничные случаи. |
| [`vite-project`](./vite-project) | Небольшое приложение на Vite и Tailwind CSS. На примере калькулятора выручки проработаны конфигурация через переменные окружения, работа с API и паттерн «Адаптер» для приведения разных источников данных к единому формату. |
| [`next-project`](./next-project) | Ранняя реализация Convertly Hub на Next.js: интерфейс для расчёта и анализа транзакций, страница источников данных, прикладные модули и API-аудит. Используются React, TypeScript, Tailwind CSS и ESLint. |
| [`hw-2026-08-03`](./hw-2026-08-03) | Проектирование трёх веб-продуктов: персонального дашборда с AI-ассистентом, интернет-магазина с админ-панелью и SaaS-конвертера файлов с публичным API. Документы содержат стек, пользовательские сценарии, безопасность и архитектурные решения. |
| [`hw-2026-08-05`](./hw-2026-08-05) | Техническая спецификация и архитектура Convertly Hub — SaaS-платформы для конвертации JPG/PNG и DOCX/PDF. Описаны Next.js, PostgreSQL/Prisma, S3-совместимое хранилище, изолированные воркеры, авторизация и rate limiting. |
| [`hw-2026-08-06`](./hw-2026-08-06) | Дизайн-этап Convertly Hub: финальная дизайн-система, токены, компоненты, варианты визуального направления и анализ референсов Vercel и Pirsch Analytics. |
| [`convertly-hub`](./convertly-hub) | Итоговая полнофункциональная реализация Convertly Hub на Next.js. Включает конвертацию файлов, публичный API и API-ключи, аккаунты и роли, личный кабинет, подписки и квоты, S3-хранилище, Prisma/PostgreSQL, Docker-конфигурации и автоматические тесты. |

## Технологии

JavaScript, TypeScript, React, Next.js, Vite, Tailwind CSS, PostgreSQL, Prisma, NextAuth/Auth.js, S3-совместимое хранилище, Docker, Jest и Playwright.

## Запуск приложений

У каждого приложения собственные зависимости и инструкции. Перейдите в нужный каталог и установите их:

```bash
cd vite-project # или next-project / convertly-hub
npm install
npm run dev
```

Для `convertly-hub` перед запуском также потребуются переменные окружения и инфраструктурные сервисы; см. его [README](./convertly-hub/README.md) и [инструкцию локального запуска](./convertly-hub/docs/local-start.md).
